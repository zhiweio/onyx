# 月度关账报告

写作指南。版式由 Word 模板固定。填写 `outputs/report.docx`，不要另写一份 markdown 报告。

1. **期间与主体** — 公司、期间、币种、单位、关账截止日。
2. **完成情况** — 银行、往来、存货、收入、费用、税金、固定资产：完成 / 进行中 / 阻塞。
3. **例外表** — 每条含科目、严重程度、金额、责任人、来源模块。阻断关账的标为高。
4. **对账结果** — 每项列出两侧余额与差额；差额为零也要写明。
5. **税会差异** — 本期识别的账面与税务处理差异。
6. **未完成项** — 被阻塞的步骤与阻塞原因，写入未决问题。
7. **结论** — 是否可以关账；不可关账时列出前置条件。

完成标准：每个阻断例外有金额与责任人；无残留 `{{placeholder}}`。
