# 靶点文献与竞争格局报告

写作指南。版式由 Word 模板固定。填写 `outputs/report.docx`，不要另写一份 markdown 报告。

1. **靶点与机制** — 靶点、通路、适应症。
2. **关键证据** — 文献与注册披露。每条含引用、日期、证据等级。
3. **竞争表** — 写入发现表：资产、阶段或风险、已知数据、东家、来源。
4. **差异化** — 机制、给药、安全窗口。无证据则写入数据缺口。
5. **空白与失败** — 已知失败与证据缺口。
6. **结论** — 对本次适应症是否值得继续。

完成标准：竞争资产有阶段与来源；无残留 `{{placeholder}}`。
