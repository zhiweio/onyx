# 数据分析报告

写作指南。版式由 Word 模板固定。填写 `outputs/report.docx`，不要另写一份 markdown 报告。

1. **分析问题** — 要回答什么；若原始需求含糊，写明采用的口径。
2. **数据概况** — 行数、字段、类型、时间范围、空值情况。
3. **数据质量** — 重复、单位不一致、缺失区间、异常值及处理方式。
4. **分析方法** — 指标定义、分母与基期。
5. **发现表** — 每条先给结论，再给数字：标题、严重程度、金额或变化、责任人、来源文件。
6. **图表** — 仅在能体现趋势或分布时给出，并说明读法。
7. **局限** — 数据无法支撑的推论，写入数据缺口。
8. **结论与建议**

完成标准：合计可从源文件复算；无残留 `{{placeholder}}`。
