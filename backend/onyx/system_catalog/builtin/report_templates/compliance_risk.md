# 合规风险预警报告

写作指南。版式由 Word 模板固定。填写 `outputs/report.docx`，不要另写一份 markdown 报告。

1. **对象** — 企业名称、统一社会信用代码、行业、地区。
2. **结论** — 风险等级（高 / 中 / 低）与一句话原因。
3. **发现表** — 每条含标题、严重程度、金额或影响、责任人、来源。来源须含 URL 或 source_id、trust_tier、日期。
4. **政策依据** — 文号、发文机关、生效日期。无文号的条目列入未决问题。
5. **未覆盖来源** — 插件未配置或查询失败，写入数据缺口。
6. **建议动作** — 可执行的下一步，每条对应一条发现。

完成标准：每条发现可回溯到来源；无残留 `{{placeholder}}`。
