# 应收账款风险清单

写作指南。版式由 Word 模板固定。填写 `outputs/report.docx`，不要另写一份 markdown 报告。

1. **口径** — 主体、基准日、币种、账龄分段。
2. **账龄结构** — 各段余额与占比。
3. **高风险客户表** — 每行：客户或事项、严重程度、余额、责任人、来源（账龄表或外部信号）。
4. **外部信号** — 诉讼、失信、评级，写明日期与权重。无则写 无。
5. **下一步** — 每个高风险行给出催收或坏账动作。
6. **结论** — 需立即跟进的客户与金额。

完成标准：高风险行有责任人与动作；无残留 `{{placeholder}}`。
