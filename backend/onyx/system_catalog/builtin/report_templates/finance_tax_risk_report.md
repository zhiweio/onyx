# 财税与经营风险分析报告

写作指南。版式由 Word 模板固定。填写 `outputs/report.docx`，不要另写一份 markdown 报告。

1. **主体与期间** — 官方名称、证券代码、五个分析年度、口径（合并报表、各年 12 月 31 日）；数据来源清单。
2. **审计意见** — 五个年度逐一核对意见类型；非标准无保留意见列为头号风险。
3. **KPI 看板** — 25 个以上指标五年横排；派生指标用公式算，不手填；洞察 5～7 条，每条点名指标与方向。
4. **三表透视** — 利润表、资产负债表、现金流量表五年并列；异动科目逐条点评并对应到事件。
5. **税负与现金流专项** — 实际所得税率、整体税负率、收现比、净现比、自由现金流；税收优惠资格与到期时间。
6. **风险识别** — 财税 TX-01～10、经营 OP-01～08；每条三段式：数据证据 → 成因 → 影响。
7. **风险矩阵** — 高=56、中=20、低=4；综合评级一段写安全垫与风险区间；立即治理与常规跟进分级。
8. **建议与整改** — 财税、资金、运营、披露四维建议表；30 日、90 日、持续监控三层整改，回扣风险编号。
9. **期后事项** — 未审计数据单独成章，标注「未经审计，仅作趋势观察」，不并入五年表。
10. **数据缺口** — 拿不到写「未获取」；转述标「转述」；每个数字可溯源到年报页码、
    原始来源名称（企查查 / 智慧芽 / 同花顺，注明具体数据项如文书号、专利号）或网页
    URL。报告里不出现 MCP 工具名、服务器名和内部文件路径——那是工作存档，读者
    只认原始来源。

完成标准：无残留 `{{placeholder}}`；章号连续、层级正确；免责声明保留；跨年口径变更已标注。
