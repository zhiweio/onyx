# 临床管线扫描

写作指南。版式由 Word 模板固定。填写 `outputs/report.docx`，不要另写一份 markdown 报告。

1. **适应症与基准日** — 适应症、检索日、纳入阶段。
2. **试验表** — 写入发现表：试验简称、阶段或风险、终点或人数、申办方、登记号。
3. **设计比较** — 人群、对照、终点、统计假设。缺项写入数据缺口。
4. **读出时间** — 已知的完成或读出日期；未知写 未获取。
5. **对己方设计的含义** — 可借鉴与需避开的选择。
6. **结论** — 竞争密度与主要设计风险。

完成标准：每条试验有登记号；无残留 `{{placeholder}}`。
