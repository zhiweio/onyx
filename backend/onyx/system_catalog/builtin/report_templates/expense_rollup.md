# 费用归集报告

写作指南。版式由 Word 模板固定。填写 `outputs/report.docx`，不要另写一份 markdown 报告。

1. **口径** — 集团或主体、期间、币种、报销文件清单。
2. **归集结果** — 按公司、部门、科目给出合计，并指向源文件。
3. **异常表** — 每行：异常标题、严重程度、金额、责任人、来源文件。包括错科目、超标、缺附件。
4. **未映射科目** — 无法归入标准科目的行，列入数据缺口。
5. **勾稽** — 归集合计与源文件合计是否一致。
6. **结论** — 可入账的范围与需退回的文件。

完成标准：合计可从源文件复算；无残留 `{{placeholder}}`。
