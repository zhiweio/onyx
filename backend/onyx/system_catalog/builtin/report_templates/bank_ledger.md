# 银行流水核对报告

写作指南。版式由 Word 模板固定。填写 `outputs/report.docx`，不要另写一份 markdown 报告。

1. **口径** — 主体、期间、币种、银行与账号清单。
2. **账面与银行余额** — 每户列出账面余额、银行余额、差额。
3. **未达账表** — 每行：事项、严重程度、金额、责任人、对账单或回单。
4. **调节验算** — 账面余额 ± 未达 = 银行余额。验算失败写入未决问题。
5. **解析失败的流水** — 列入数据缺口。
6. **结论** — 是否可以关账该模块。

完成标准：差额为零也写明；每条未达有日期与方向；无残留 `{{placeholder}}`。
