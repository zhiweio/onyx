# CMC 与质量风险简报

写作指南。版式由 Word 模板固定。填写 `outputs/report.docx`，不要另写一份 markdown 报告。

1. **产品与市场** — 剂型、规格、目标市场。
2. **属性对照** — 每个质量属性对应指导原则或标签章节。
3. **风险表** — 写入发现表：属性、严重程度、已知限度或事件、责任人、来源。
4. **召回与缺陷** — 日期、市场、原因。无则写 无。
5. **草案与生效文件** — 草案不得写成强制要求。
6. **结论** — 当前最大的药学风险与需补的研究。

完成标准：每条风险有属性与来源；无残留 `{{placeholder}}`。
