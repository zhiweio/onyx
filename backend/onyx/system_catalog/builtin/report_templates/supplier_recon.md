# 供应商对账报告

写作指南。版式由 Word 模板固定。填写 `outputs/report.docx`，不要另写一份 markdown 报告。

1. **口径** — 主体、期间、币种、应付账与对账单文件。
2. **匹配键** — 使用的匹配顺序（税号、发票号、金额+日期）。未用的键写明原因。
3. **差异表** — 每行：差异标题、严重程度、金额、责任人、两侧来源。
4. **分类汇总** — 未入账、重复、金额不符、供应商不符、时间差。每类给金额合计。
5. **无法解析的文件** — 列入数据缺口，不丢弃。
6. **结论** — 可签署的差异余额；为零也要写明。

完成标准：每条未匹配差异有分类与金额；无残留 `{{placeholder}}`。
