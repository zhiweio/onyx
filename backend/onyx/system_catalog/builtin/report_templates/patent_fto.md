# 专利自由实施评估

写作指南。版式由 Word 模板固定。填写 `outputs/report.docx`，不要另写一份 markdown 报告。

1. **范围** — 产品要素、司法辖区、基准日。
2. **专利族** — 公开号、权利人、申请日、预计到期或排他期。期限与排他分开写。
3. **权利要求对照表** — 写入发现表：权利要求要点、风险等级、重叠要素、责任人、专利号。
4. **结论风险** — 阻断、需设计规避、或未发现阻断。这不是法律意见。
5. **未检索到的库** — 写入数据缺口。
6. **下一步** — 需律师复核的权利要求。

完成标准：阻断项指向专利号与要素；无残留 `{{placeholder}}`。
