# 政策趋势研判报告

写作指南。版式由 Word 模板固定。填写 `outputs/report.docx`，不要另写一份 markdown 报告。

1. **范围** — 税种、行业、地区、时间窗、基准日。
2. **变化摘要** — 官方文件与新闻分列。新闻只用于发现原文。
3. **发现表** — 每条政策变化：标题、严重程度、金额或影响、责任人、来源文号。
4. **影响对象** — 谁受影响、如何受影响、从何日开始。
5. **时间线** — 发布、生效、过渡。状态必须核实，不得假设。
6. **待核实** — 缺文号或仅有新闻转述的条目，写入未决问题。

完成标准：每条官方引用有文号、机关、日期；无残留 `{{placeholder}}`。
