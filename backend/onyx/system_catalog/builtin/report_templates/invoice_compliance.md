# 发票合规审查报告

写作指南。版式由 Word 模板固定。填写 `outputs/report.docx`，不要另写一份 markdown 报告。

1. **口径** — 主体、期间、币种、扫描文件清单与份数。
2. **检查范围** — 必填项、税号、税率、作废与红冲、三流一致。
3. **例外表** — 每行：例外标题、严重程度、金额、责任人、来源文件名。阻断抵扣的标为高。
4. **按规则汇总** — 每条规则的通过数、失败数、未检数。
5. **扫描失败** — OCR 失败或无法打开的文件，列入数据缺口。
6. **结论** — 是否可以进入认证或抵扣；不可时列出前置条件。

完成标准：每条例外指向文件与字段；无残留 `{{placeholder}}`。
