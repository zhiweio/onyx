# 注册申报路径

写作指南。版式由 Word 模板固定。填写 `outputs/report.docx`，不要另写一份 markdown 报告。

1. **产品与阶段** — 产品、当前阶段、目标市场清单。
2. **路径表** — 写入发现表：市场或模块、风险、缺失证据、责任人、指导原则。
3. **证据包** — 各阶段所需研究或模块，对照现有资料。
4. **沟通节点** — 已知会议或咨询；无记录写 未获取。
5. **缺口** — 缺哪项研究才能进入下一阶段。
6. **结论** — 各市场的推荐路径与最早可行时间（未知则写未知）。

完成标准：每个缺口指向模块或研究；无残留 `{{placeholder}}`。
