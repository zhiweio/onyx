# 药物立项评估报告

写作指南。版式由 Word 模板固定。填写 `outputs/report.docx`，不要另写一份 markdown 报告。

1. **资产与适应症** — 分子或项目名、适应症、当前阶段。缺一不可。
2. **决策问题** — 本次要回答 go / hold / no-go 中的哪一个，以及决策日期。
3. **证据表** — 每行：主张、证据等级、来源、日期。文献、试验、专利、CMC 分列。
4. **决策因子打分** — 未满足需求、竞争、可成药性、安全性、CMC、监管路径。每项给分并引用。
5. **主要风险** — 每条写入发现表：标题、严重程度、金额或影响、责任人、来源。
6. **未决问题** — 缺什么证据才能改结论。
7. **数据缺口** — 未检索到或工具失败的来源。
8. **结论** — 明确建议与前置条件。

完成标准：每个决策因子有引用；发现表无空行；Word 中无残留 `{{placeholder}}`。
