# 临床期立项调研报告

写作指南。本模板是契约式:版式由渲染器统一生成,章节结构由你按证据组织。
契约约束「必须为真、必须包含」,不约束章节排布——结构相似,不雷同。

## 必答问题(报告必须逐条回答)

1. 资产与适应症是什么,当前处于什么阶段?
2. 本次要回答 go / hold / no-go 中的哪一个,决策日期是何时?
3. 每个决策因子的证据与打分是什么?
4. 主要风险与未决问题有哪些?
5. 最终建议与前置条件是什么?

## 必备产物(缺一不过质量门)

- 资产与适应症声明:分子或项目名、适应症、当前阶段,缺一不可。
- 证据表:每行「主张、证据等级、来源、日期」;文献、试验、专利、CMC 分列。
- 决策因子打分:未满足需求、竞争、可成药性、安全性、CMC、监管路径,
  每项给分并附引用。
- 发现表:标题、严重程度、金额或影响、责任人、来源。
- 未决问题:缺什么证据才能改变结论。
- 数据缺口:未检索到或工具失败的来源。
- 结论:明确建议 + 前置条件。

## 叙事脊柱(引导,不是硬性章节)

资产与决策问题 → 证据与打分 → 风险与未决 → 结论与前置条件

在此弧线内:章节可增删、合并、重命名;证据分册(文献/试验/专利/CMC)
按材料的实际分布组织。

## 硬规则

1. 每个决策因子都有引用(文献号/试验登记号/专利号);无引用不打分。
2. 每个数字、每条发现可溯源:原始来源名称或网页 URL 与访问日期。
3. 报告正文不出现 MCP 工具名、服务器名、outputs/ 等内部路径与脚本名。
4. 拿不到的数据写「未获取」并写原因;转述标「转述」。

## 交付与自检

交付 `outputs/report.md`;版式由平台渲染 DOCX,不要手写转换脚本。
Craft 沙箱内交付前用平台工具 `check_report` 自检并修完全部 FAIL 项。

## 组件与图表

- KPI 指标条:` ```kpi ` 围栏,每行 `指标 | 值 | 状态`;状态词 预警/恶化/偏高/偏低/关注
  显红,改善/达标/稳健 显绿,其余中性蓝。
- 提示框:`> [!风险] 标题`(红)、`> [!洞察] 标题`(蓝)、`> [!提示] 标题`(灰蓝),
  正文跟在后续 `>` 行。
- 数据表:GFM 表格;**表格下一行写来源**,每张表都要有。
- 图表:`![图题](outputs/charts/NN.png)` 独立成段,PNG 先行产出。

## 完成标准

- 无残留 {{占位符}}。
- 章号连续,标题按内容自拟。
- 每个决策因子有引用;发现表无空行。
- 图表不少于 3 张(竞争格局、打分对比、读出时间为基线)。
