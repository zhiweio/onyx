# 会议纪要

写作指南。版式由 Word 模板固定。填写 `outputs/report.docx`，不要另写一份 markdown 报告。

1. **会议信息** — 主题、日期、时长、参会人。写入 `meeting_title` 与 `attendees`。
2. **决议** — 每条只写结论，不含讨论过程。
3. **行动项表** — 每行：动作、负责人、截止日期、状态、备注。缺失负责人写 未指定。
4. **讨论摘要** — 仅保留支撑决议的背景。
5. **分歧** — 未达成一致的观点，分别记录。
6. **待定问题** — 需要会后确认的事项与确认人。

完成标准：每个行动项有负责人或明确标为未指定；无残留 `{{placeholder}}`。
