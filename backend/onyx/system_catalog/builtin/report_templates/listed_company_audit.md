# 上市公司财务审计报告

写作指南。版式由 Word 模板固定。填写 `outputs/report.docx`，不要另写一份 markdown 报告。

1. **主体** — 官方名称、证券代码、交易所、统一社会信用代码；来源文件。
2. **口径** — 期间、币种、单位、会计准则；数据来源。
3. **勾稽检查** — 净利润、未分配利润、货币资金。失败写入发现表。
4. **关键比率** — 每项列出公式、取数科目、本期值与对比期值。
5. **行业与同业** — 指数、同业名单、对比口径。
6. **信用与司法** — 诉讼、处罚、股权与经营风险，带来源。
7. **专利与研发** — 仅引用 replay_store 中的捕获；附 检索深度对账表。
8. **红蓝复核** — 未关闭的质疑不得写成结论。
9. **数据问题** — 缺失、重述、口径变更。
10. **结论** — 结论及需进一步核实的事项。

完成标准：无残留 `{{placeholder}}`；无来源的数字不得写入结论。
