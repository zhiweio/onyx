# 财务报表分析报告

写作指南。版式由 Word 模板固定。填写 `outputs/report.docx`，不要另写一份 markdown 报告。

1. **口径** — 期间、币种、单位、会计准则；数据来源文件。
2. **勾稽检查** — 净利润与未分配利润、现金流量表与货币资金。失败写入发现表。
3. **结构分析** — 资产负债结构、收入与成本结构，含同比 / 环比。
4. **关键比率** — 每项列出公式、取数科目、本期值与对比期值。
5. **变动归因** — 每项显著变动指向具体科目与业务原因，写入发现表。
6. **现金质量** — 经营活动现金流与净利润的匹配情况。
7. **数据问题** — 缺失、重述、口径变更，写入数据缺口。
8. **结论** — 结论及需进一步核实的事项。

完成标准：勾稽失败不得省略；无残留 `{{placeholder}}`。
