# 调研简报

写作指南。版式由 Word 模板固定。填写 `outputs/report.docx`，不要另写一份 markdown 报告。

1. **问题与范围** — 要回答的问题、时间窗、明确排除的内容。
2. **结论摘要** — 三到五条，每条可独立成立。
3. **发现表** — 按主题归类。每条含标题、严重程度或置信、影响、责任人、来源 URL 与日期。
4. **来源分级** — 区分一手来源与二手转述。
5. **分歧点** — 来源冲突之处及哪一方证据更强。
6. **信息缺口** — 未能确认的内容，以及需要什么才能确认。
7. **建议下一步** — 可执行的检索或验证动作。

完成标准：每条实质主张有引用；无残留 `{{placeholder}}`。
