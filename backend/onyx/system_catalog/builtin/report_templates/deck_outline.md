# 演示文稿大纲

写作指南。先填这份 Word 大纲，再按页序做 `outputs/deck.pptx`。不要跳过大纲。

1. **受众与场合** — 谁看、多长、要他们做什么决定。
2. **一句话结论** — 写入 `key_message`。先结论后细节。
3. **幻灯片表** — 每行一页：页标题、该页要点、证据、受众、备注。
4. **数字来源** — 每页用到的数字指向简报或数据文件。
5. **不讲的内容** — 明确排除，避免现场展开。
6. **结论页** — 决策请求与未决问题。

完成标准：页数与随后做成的 PPT 一致；无残留 `{{placeholder}}`。
