# 费用波动分析报告

写作指南。版式由 Word 模板固定。填写 `outputs/report.docx`，不要另写一份 markdown 报告。

1. **口径** — 主体、本期、对比期、币种、单位。
2. **波动表** — 每行：科目或部门、严重程度、金额差、责任人、来源。
3. **归因** — 每项重大波动指向业务原因。无法归因的写入未决问题。
4. **口径变更** — 重述、科目重分类、组织变更单独列出，不混入经营波动。
5. **数据缺口** — 缺对比期或单位不一致的行。
6. **结论** — 需管理层关注的三条波动。

完成标准：重大行有金额与原因或明确标为未决；无残留 `{{placeholder}}`。
