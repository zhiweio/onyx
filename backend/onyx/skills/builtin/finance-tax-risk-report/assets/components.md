# 组件手册

渲染器认识的全部构件。组件按需选用,数量与排布由证据决定;
样式(配色、字体、表格底纹、提示框)由渲染器统一套用,写作时只管语义。

## KPI 指标条

```` ```kpi ```` 围栏,每行 `指标名 | 当前值 | 状态`。渲染为大数字卡片横排,
一行最多 4 个。

- 状态词驱动颜色:`预警 / 恶化 / 偏高 / 偏低 / 高风险 / 关注` 显示警示红,
  `改善 / 达标 / 健康 / 稳健` 显示绿,其余中性蓝。
- 用在执行摘要(核心 6~8 个)与各分析节的当节关键指标。
- 值必须与正文、表格一致,取自 `kpi_dashboard.json`,不手填两份。

````
```kpi
营业收入 | 4.73 亿元 | 关注
归母净利润 | 0.90 亿元 | 改善
净现比 | 0.48 | 预警
```
````

## 提示框

引用块首行 `[!类型] 标题`,正文跟在后续 `>` 行。三类:

- `> [!风险]` — 高危事项:优惠到期、复审失败、赔付风险。红。
- `> [!洞察]` — 关键判断:数据背后的含义。蓝。
- `> [!提示]` — 口径说明、数据局限。灰蓝。

每个报告 4~6 处,不刷屏。正文短,一段说清。

## 数据表

GFM 表格。约定:

- 表头一行,行按数据增删,不硬凑;空值写「未获取」。
- 年份列从新到旧或从旧到新,全文一个方向。
- **表格下一行写来源**:`来源: 公司2024年年度报告第 5 页。`
  每张表都要有,这是质量门。
- 透视表后加「透视分析:①…②…」逐条点评,对应到事件。

## 图表

`![图题](outputs/charts/NN_name.png)` 独立成段(前后空行)即嵌图,
渲染自动带题注。图先由 vivid-figures-skill(优先)或 chart-gen 产出到
`outputs/charts/`,一律 PNG,命名 `NN_英文名.png`。本约定只约束 markdown/Word
交付;HTML 演示交付(deck)由 slideblocks 内置渲染路径绘图,不嵌 PNG。

- 全篇不少于 5 张;基线五图见 `references/report-template.md` 图表清单。
- 每图的数据取自 `kpi_dashboard.json`,不在图里手填第二份。

## 目录与封面

不手写。封面来自 markdown 头部 frontmatter(公司、证券代码、数据基准日、
编制日期、免责声明),目录由平台导出 DOCX 时自动插入目录域。

## 交付前自检

平台工具 `check_report`:传 `markdown`(完整报告)与 `contract`(模板契约),
返回占位符、必备产物、章号、图表数、来源行、内部路径各项检查。
FAIL 项修完再交付。
