# 交付自检清单

生成 docx 前逐条过。任何一条不过就修完再交付。本清单针对历史上手工成稿
报告的真实缺陷逐条设卡。

## 数据

1. KPI 看板、三表透视、年报摘要三级对账一致；勾稽（未分配利润、资产=负债+权益、
   期末现金≈货币资金）通过。
2. 每个数字可溯源：年报页码、原始来源名称（企查查 / 智慧芽 / 同花顺，注明具体
   数据项如文书号、专利号），或网页 URL 与访问日期，三选一。
3. 报告正文零内部痕迹：不出现 MCP 工具名、服务器名（`qcc-*`、`hithink-*` 等）、
   `outputs/` 等内部文件路径、脚本名——内部存档只用于复核，不进报告。
4. 拿不到的数据写「未获取」+ 原因。没有零填充、没有插值、没有臆造。
5. 转述数据标「转述」或「估算」；期后数据标「未经审计，仅作趋势观察」。
6. 跨年口径提示到位：会计政策变更、合并范围变化年份已标注不可机械横比。
7. 全文单位一致（亿元 / 百万元 / %），同一指标全文一个口径。

## 结构

8. 章号连续不重复不跳号（一、二、…十二 + 期后 / 附录）；脚本自动编号已生效。
9. 标题层级正确：H1=章、H2=节、H3=子目，无跳级、无错位。
10. 十二章骨架齐全，顺序与模板一致；风险条目编号 TX-01～TX-10、OP-01～OP-08
    连续。
11. 每条风险卡片三段式完整：数据证据（带数值与来源）→ 成因分析（①②③）→
    潜在影响（①②③）。
12. 整改三层（30 日 / 90 日 / 持续监控）齐全，且每条回扣风险编号。
13. 结论给闭环主线，逐条回答；先安全垫、再否定「恢复=风险消失」。

## 格式（docx）

14. 目录是 Word 域（可 F9 更新），不是手打文本；标题用了真实标题样式。
15. 提示框是带底纹段落，不是 1×1 表格；全文无 1×1 残留表格。
16. 表格样式统一：表头加粗深底白字，无断裂列；看板表无重复年份列。
17. 图表全部嵌入成功（文件存在、非空白）；每图有图题与口径说明。
18. 封面信息完整：公司名、证券代码、报告名、期间、资料范围、分析日期；
    无「草稿」「待修改」等残留字样。
19. 页眉页脚正常：页脚页码域生效。

## 合规

20. 免责声明完整保留在文末。
21. 无投资建议、无买卖点、无估值结论；风险表述自我设界（「可能」「或将」），
    无「必然」「肯定」式断言。
22. 引用的公告、新闻、政策均注明日期与 URL；不虚构案号、统一社会信用代码、
    专利号。
23. `outputs/` 交付物齐全：report.docx、statements.json、kpi_dashboard.json、
    charts/、mcp 原始 JSON（存档与复核用，不出现在报告引用里）。
