# 报告内容契约与选配库

按契约四幕脊柱组织的内容要素要点、标准表格规格、标准图表清单与写作规范。
填充对象是 `assets/report_template.md`(起始骨架,章节自组织);
版式由平台按模板主题渲染。

## 规模与深度

- 正文约 2.5 万～3 万字,表格 12～17 张,图表 10～14 张(最低 8 张)。
- 每章短段推进。一段只说一件事,先数据后判断。
- 面向读者是老板:每幕给出「所以怎么办」的落点,不停留在指标罗列。
- 章节沿脊柱自组织:标题按内容起、章号连续;同结构不同公司的报告相似但不雷同。

## 第一幕:总览(执行摘要 + 核心看板)

- 执行摘要三五段:公司干什么、五年轨迹定性(V/M/W 型)、最重要的三个发现、
  总体评级方向。先结论后细节,给老板能直接引用的话。
- KPI 指标条呈现核心 6~8 个指标;完整看板表 25~27 个指标五年横排,
  行清单见 `metrics-handbook.md`;紧随关键洞察 5~7 条,每条点名指标、方向、
  幅度与含义。
- 审计意见五年逐一写明;非标准无保留意见必须升级为头号风险。

## 第二幕:数据与趋势(三表透视 + 专项分析)

- 数据基础:主体识别、口径与时点、数据来源编号清单、会计政策变更与可比性提示。
- 趋势五看:营收与利润、盈利能力与费用、资产与分产品结构、营运效率与
  现金流质量、资本结构与偿债——按证据分节,不必五个齐。
- 三表五年并列透视表(科目行见 `metrics-handbook.md`),每表后「透视分析」
  ①②③④逐条点评异动科目并对应事件。
- 税务与现金专项:实际所得税率 vs 法定税率、整体税负率、优惠资格与到期、
  收现比、净现比、自由现金流、资金分层。

## 第三幕:风险(识别 + 矩阵 + 专题)

- 风险卡片按 `risk-framework.md` 识别,三段式:**数据证据**(数值+年份+来源)→
  **成因分析**(①②③)→ **潜在影响**(①②③)。
  - 财税 TX-xx(约 4~10 条):税负率异常、税会差异、出口退税与跨境、
    优惠续期、发票申报、政府补助、转让定价、财产行为税。
  - 经营 OP-xx(约 3~8 条):收入现金质量、客户集中、存货减值、资本开支、
    研发替代、用工、资本配置、周期波动。
- 风险矩阵表:全部条目(编号 / 风险点 / 等级 / 风险评分 / 处置建议),
  评分映射 56/20/4;综合评级一段(安全垫 → 风险区间 → 立即治理项)。
- 重大专题 2~5 个单独成节,不进矩阵:投资成败复盘、募投变更、海外重构、
  审计机构更换、实控人与治理、会计判断争议。写法:事实 → 意味着什么 → 建议动作。

## 第四幕:建议与结论(整改 + 期后 + 免责)

- 整改三层:30 日 / 90 日 / 持续监控,每条回扣 TX/OP 编号;建议可按
  财税、资金、运营、披露四维组织,用建议表(建议项 / 优先级 / 实施周期 /
  落地措施与预期收益),收益尽量量化。
- 核查程序表:风险领域 / 等级 / 核心问题 / 建议程序(函证、期后回款、
  截止测试、减值测试、穿行测试)。
- 期后事项:单独成节,标注「未经审计,仅作趋势观察」,不并入五年表。
- 结论闭环:新增收入能否转化为可持续扣非利润 → 利润能否形成匹配经营现金流 →
  资本投入能否提高资产回报 → 风险敞口能否被内控覆盖,逐条回答必答问题。
- 附录:主要资料来源清单(编号 + 页码/URL + 访问日期)、建议进一步取得的资料、
  免责声明。

## 写作规范

- 风险标题格式:【TX-01·高】实际所得税率突破法定税率。
- 判断必须附量化证据并自我设界:「不代表已经存在财务错报」「不能简单等同」
  「不应据此推断」。
- 转述写法:「公司解释为……」「披露理由包括……」,注明公告日期。
- 引用来源用读者看得懂的原始名称:年报标页码;企查查 / 智慧芽 / 同花顺数据注明
  来源与具体数据项(处罚文书号、案号、专利号、同业公司名);网页标原始 URL 与
  访问日期。报告里禁止出现 MCP 工具名、服务器名(`qcc-*`、`hithink-*` 等)和
  `outputs/` 内部文件路径。
- 提示框:高危事项用 `> [!风险]`,关键判断用 `> [!洞察]`,口径说明用
  `> [!提示]`。每个报告 4~6 处。
- 指标名首次出现给公式或口径;单位全文统一(亿元 / 百万元 / %)。
