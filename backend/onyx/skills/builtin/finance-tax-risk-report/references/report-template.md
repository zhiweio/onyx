# 报告模板与图表清单

报告模板十二章骨架、标准表格规格、标准图表清单与写作规范。
填充对象是 `assets/report_template.md`；Word 版式由官方模板
`finance_tax_risk_report` 固定（场景链路）或由 `build_report_docx.py` 生成（技能链路）。

## 规模与深度

- 正文约 2.5 万～3 万字，表格 12～17 张，图表 10～14 张。
- 每章短段推进。一段只说一件事，先数据后判断。
- 面向读者是老板：每章给出「所以怎么办」的落点，不停留在指标罗列。

## 十二章骨架逐章要点

### 一、报告说明与数据来源

- 分析对象、证券代码、五个分析年度、口径（合并报表、时点各年 12 月 31 日）。
- 审计意见：五个年度逐一写明意见类型。非标准无保留意见必须升级为头号风险。
- 数据来源编号清单：年报 PDF（标注文件与页码区间）、公告、MCP 工具、网页 URL。
- 会计政策变更与口径提示（如准则解释 18 号、20 号），写明影响哪些年度可比性。

### 二、老板数据看板（核心 KPI 速览）

- KPI 看板表：25～27 个指标五年横排，行清单见 `metrics-handbook.md`。
- 关键洞察 5～7 条，编号列出。每条点名指标、方向、幅度与含义。
  写法示例：「实际所得税率从 2021 年 17.9% 逐年抬升至 2025 年 29.1%，首次突破
  母公司 25% 法定税率——这是本报告最重要的财税风险信号，指向亏损子公司税盾
  未充分使用与跨境利润分配不平衡。」

### 三、经营与财务趋势分析

五个小节，每节「表或图 + 三五段解读」：

1. 营收与利润趋势——五年曲线 + 同比，给趋势定性标签（V 型、M 型、W 型）。
2. 盈利能力与费用水平——毛利率、净利率、费用率走向及驱动。
3. 资产结构与分产品 / 分地区收入——结构变化与集中度。
4. 营运效率与现金流质量——周转天数、收现比、净现比。
5. 资本结构与偿债能力——资产负债率、有息负债、利息保障倍数。

### 四、五年财务数据透视

三张五年并列透视表（利润表 / 资产负债表 / 现金流量表，科目行见
`metrics-handbook.md`），每表后附「透视分析」①②③④逐条点评异动科目，
并对应到具体事件（减值、转股、政策变更、大客户波动）。

### 五、税务与现金专项分析

- 税负水平趋势：实际所得税率 vs 法定税率、整体税负率、税收优惠资格与到期时间、
  出口退税 / 加计扣除等专项依赖度。
- 现金流专项：经营现金流与净利润背离、收现比走势、自由现金流、资金分层
  （受限资金、理财、可用现金）。

### 六、财税风险分析及识别点（TX-01～TX-10）

按 `risk-framework.md` 识别并写三段式卡片。常见方向：税负率异常、历史融资工具
税会差异、出口退税与跨境税务、税收优惠续期、发票与申报纪律、政府补助合规、
转让定价、财产行为税。文末可加「其他财税风险汇总表」（序号 / 主要风险 / 等级 /
关键证据）。

### 七、经营风险识别（OP-01～OP-08）

同上三段式。常见方向：收入现金质量、客户集中、存货与减值、资本开支与产能、
研发与技术替代、用工与人才、资本配置与分红、周期与行业波动。

### 八、重大专题与治理风险

2～5 个专题，每题一节，不进风险矩阵但必须写。选题库：重大投资成败复盘、
募投项目变更与资金效率、海外基地与供应链重构、审计机构更换、董事长 / 总经理 /
财务负责人变动、实控人与家族治理、会计政策与判断争议。写法：事实 → 意味着什么 →
建议动作。

### 九、专业改进建议

四个维度，前三维用建议表（建议项 / 优先级 / 实施周期 / 落地措施与预期收益）：

1. 财税合规与税务筹划建议（5～6 项，含量化节税收益）。
2. 资金管理与现金流改善建议（4～5 项）。
3. 经营与运营改进建议（5～6 项）。
4. 信息披露与治理改进建议（叙述式）。

措施要落到字母编号 a) b) c)，预期收益尽量量化（如「高新复审通过后年节税约
1300 万元」）。

### 十、风险矩阵与综合评级

- 风险矩阵表：TX + OP 全部条目（编号 / 风险点 / 等级 / 风险评分 / 处置建议）。
- 综合评级一段：先给安全垫判断（杠杆、现金、审计意见），再给风险区间定性
  （如「中等偏高风险区」），点名需立即治理的高优先级风险。
- 建议治理机制：董事会下设风险管理委员会，每季度审议风险矩阵更新。

### 十一、优先级整改建议（含核查程序）

- 三层时间轴：第一优先级 30 日内 / 第二优先级 90 日内 / 第三优先级持续监控。
  每层 4～5 条编号动作，必须回扣前文风险编号。
- 核查程序表：风险领域 / 等级 / 核心问题 / 建议程序。程序用审计口吻
  （函证、期后回款、截止测试、减值测试、穿行测试、压力情景测算）。

### 十二、结论（闭环式收尾）

三段式：先给安全垫判断（无持续经营 / 偿债危机、审计意见），再否定
「恢复 = 风险消失」，最后给闭环主线并逐条回答。闭环示例：新增收入能否转化为
可持续扣非利润 → 利润能否形成匹配的经营现金流 → 资本投入能否提高资产回报率 →
跨境 / 融资 / 税收优惠 / 交接能否被内控覆盖。

### 附录与免责声明

- 附录一：主要资料来源（编号清单，含 URL 与页码）。
- 附录二：建议进一步取得的资料。
- 免责声明：保留模板原文，说明数据来源、口径、时点、局限性，声明不构成
  投资建议，要求与审计报告和问询函回复交叉验证。

## 写作规范

- 风险标题格式：【TX-01·高】实际所得税率突破法定税率。
- 三段式卡片：**数据证据**（数值 + 年份 + 来源）→ **成因分析**（①②③④）→
  **潜在影响**（①②③④）。
- 判断必须附量化证据并自我设界：「不代表已经存在财务错报」「不能简单等同」
  「不应据此推断」。
- 转述写法：「公司解释为……」「披露理由包括……」，注明公告日期。
- 引用来源用读者看得懂的原始名称：年报标页码；企查查 / 智慧芽 / 同花顺数据注明
  来源与具体数据项（处罚文书号、案号、专利号、同业公司名）；网页标原始 URL 与
  访问日期。报告里禁止出现 MCP 工具名、服务器名（`qcc-*`、`hithink-*` 等）和
  `outputs/` 内部文件路径。
- 提示框：高危事项用 `> [!风险]`，关键提醒用 `> [!洞察]`。每个报告 4～6 处。
- 指标名首次出现给公式或口径；单位全文统一（亿元 / 百万元 / %）。
