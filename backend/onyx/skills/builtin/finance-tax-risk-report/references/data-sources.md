# 数据源手册

年报 PDF 解析、MCP 工具映射、网页渠道与数据核验规则。

## 年报 PDF：结构与定位

A 股年报（沪深主板）是标准十节结构：

| 节 | 内容 | 对本报告的价值 |
| --- | --- | --- |
| 第二节 公司简介和主要财务指标 | 主要会计数据、主要财务指标、分季度数据、非经常性损益 | 五年 KPI 的权威摘要，先抄这里再进报表 |
| 第三节 管理层讨论与分析 | 经营讨论、行业、收入成本、费用、研发、现金流、风险因素 | 趋势分析、分产品分地区收入、行业对照 |
| 第四节 公司治理 | 董监高、薪酬、变动 | 治理风险专题 |
| 第六节 重要事项 | 承诺、担保、诉讼、关联交易、募投变更 | 重大专题与或有负债 |
| 第十节 财务报告 | 审计报告 + 四表 + 附注 | 三表透视、附注明细、审计意见 |

提取方法（脚本自动做）：

```
python .opencode/skills/finance-tax-risk-report/scripts/extract_annual_report.py \
  --pdf attachments/雪龙集团2024.pdf --year 2024 --out outputs/analysis [--tables]
```

1. pypdf 读书签（outline）定位各节起始页；无书签则扫描页首行「第X节」。
2. 输出 `outputs/analysis/annual_<year>/<section>.txt` 与 `manifest.json`
   （页码范围、审计意见类型、目录线索）。
3. `--tables` 对定位页用 pdfplumber 抽表格（sandbox 已装；缺失则跳过并提示）。
4. 审计意见必须读：标准无保留 / 保留 / 无法表示 / 否定 + 强调事项段。

手工要点：主要会计数据通常在第二节第 4～7 页；非经常性损益明细、前五大客户、
分产品毛利、分地区收入在 MD&A 与附注；政府补助、递延收益、税收优惠在附注。

## MCP 工具映射（按需启用，不要开齐）

| 分析需求 | Server | 取什么 | 内部存档 |
| --- | --- | --- | --- |
| 公司名 → 代码、基本信息 | `hithink-meta` / `qcc-company` | 证券代码、官方名、统一社会信用代码 | `outputs/mcp/hithink/`、`outputs/mcp/qichacha/` |
| 五年财务交叉核对 | `hithink-a-share` | 财务报表、关键指标；与 PDF 对账 | `outputs/mcp/hithink/` |
| 行业与同业对标 | `hithink-a-share-index` | 行业成分、同业名单与均值 | `outputs/mcp/hithink/` |
| 股权结构与实控人 | `qcc-company`、`qcc-executive` | 股东链、高管、关联方 | `outputs/mcp/qichacha/` |
| 涉诉、失信、处罚 | `qcc-risk`、`qcc-legal-case` | 诉讼、行政处罚、经营异常 | `outputs/mcp/qichacha/` |
| 经营与招投标 | `qcc-operation` | 经营动态、招投标、变更记录 | `outputs/mcp/qichacha/` |
| 信用与经营画像 | `company-credit`、`company-profile`、`company-risk` | 信用分、经营画像、风险摘要 | `outputs/mcp/zhihuiya/` |
| 专利与研发 | `patsnap-search`（深挖才加） | 专利数量、趋势、同业对比 | `outputs/mcp/zhihuiya/` |

规则：与 PDF 冲突时以年报 PDF 为准，差异写进报告；企查查历史数据
（`qcc-history`）需企业证书，默认不用；原始响应不删改，供复核。
「内部存档」只用于复核与回放——报告引用一律按下面的引用规范写。

## 引用规范（报告是给读者看的）

报告正文与附录只出现读者看得懂的原始来源，禁止出现 MCP 工具名、服务器名
（`qcc-*`、`hithink-*` 等）和 `outputs/` 内部路径：

| 内部来自 | 报告引用写法 | 尽量注明到 |
| --- | --- | --- |
| qcc-* 各 server | 企查查 | 具体数据项：处罚决定文书号、案号、统一社会信用代码、股东名 |
| company-* / patsnap-* | 智慧芽 | 专利号与专利名称、检索日期 |
| hithink-* | 同花顺（iFinD） | 指标名、同业公司名、报告期 |
| 年报 / 公告 PDF | 公司 2024 年年度报告第 X 页；巨潮资讯网 + URL | 页码 / 公告日期 |
| 网页检索 | 原始链接 + 访问日期 | 网站名（如 国家统计局、上海税务局） |
| 转述 | 标「转述」或「估算」 | 原始出处 |

示例：「根据企查查行政处罚记录（甬市监罚〔2024〕XX 号），子公司于 2024 年
11 月因发票违规被罚款 2 万元。」而不是「根据 qcc-risk 返回数据」。

## 网页渠道（websearch → webfetch，先搜后抓）

| 渠道 | 用途 | 入口 |
| --- | --- | --- |
| 巨潮资讯网 | 年报、公告、问询回复 PDF | static.cninfo.com.cn / www.cninfo.com.cn |
| 上交所 / 深交所 | 定期报告、监管函件 | www.sse.com.cn / www.szse.cn |
| 公司 IR 页面 | 业绩说明会纪要、投资者关系记录 | 公司官网 investor 栏目 |
| 雪球等社区 | 公告转述线索（一律标「转述」） | stockmc.xueqiu.com |
| 税务总局及地方局 | 高新认定条件、优惠政策原文 | chinatax.gov.cn 各地方站 |
| 行业协会 | 行业产量、增速、运行数据 | 各行业协会官网 |
| 国家统计局 | 宏观与行业统计 | stats.gov.cn |
| 信用中国 / 监管局 | 行政处罚公示 | creditchina.gov.cn |

抓取纪律：引用具体 URL 与访问日期；PDF 存 `outputs/sources/`；
付费墙与登录墙内容不绕过，标「未获取」。

## 期后事项处理

- 范围：分析期末之后至成稿日的季报 / 半年报、业绩预告、高管变动、定增与
  终止、重大诉讼、授信、审计机构变更、股价与评级事件。
- 一律单独成章（期后事项与外部信息表：事项 / 公开信息 / 分析影响），
  标注「未经审计，仅作趋势观察」，不并入五年三表。
- 半年报指标可建期后同比小表（指标 / 上年同期 / 本期 / 同比变化 / 分析）。

## 数据核验规则（写报告前必做）

1. 三级对账：KPI 看板 ↔ 三表透视 ↔ 年报摘要（第二节），同一指标三处一致。
2. 勾稽：净利润 → 期初未分配利润 + 净利润 − 分红 = 期末未分配利润；
   资产 = 负债 + 权益；现金流量表期末现金 ≈ 货币资金（差异查受限资金）。
3. 单位统一：正文亿元、表格按表头标注；换算误差 >0.5% 必须查原因。
4. 同名指标口径唯一：全文一个 ROE 口径、一个收现比口径。
5. 每个数字绑定来源：年报页码、原始来源名称（企查查 / 智慧芽 / 同花顺 + 具体
   数据项），或网页 URL。三者取一，写不出来的数字删掉或标「未获取」。来源引用
   按「引用规范」写，内部存档路径不得出现在报告里。
