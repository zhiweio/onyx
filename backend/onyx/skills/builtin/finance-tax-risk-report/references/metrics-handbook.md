# 指标口径手册

所有派生指标用公式算，不手填。本文件定义公式、看板行清单、预警阈值与组合信号。
`scripts/compute_metrics.py` 按本文件实现，产出 `outputs/analysis/kpi_dashboard.json`。

## 公式口径（首次出现必须写进报告）

| 指标 | 公式 | 说明 |
| --- | --- | --- |
| 毛利率 | 1 − 营业成本 / 营业收入 | 会计政策变更年度要标注不可比 |
| 归母净利率 | 归母净利润 / 营业收入 | |
| ROE | 归母净利润 / 年末归母权益 | 如公司披露加权口径，优先用披露值并注明 |
| 销售费用率 | 销售费用 / 营业收入 | |
| 研发费用率 | 研发费用 / 营业收入 | |
| 期间费用率合计 | (销售 + 管理 + 研发 + 财务费用) / 营业收入 | |
| 实际所得税率 | 所得税费用 / 利润总额 | 突破 25% 法定税率为头号财税信号 |
| 整体税负率 | 支付的各项税费 / 营业收入 | 来自现金流量表 |
| 收现比 | 销售商品提供劳务收到的现金 / 营业收入 | ≥1 为健康 |
| 净现比 | 经营活动净现金流 / 净利润 | ≥0.8 为健康 |
| 简化自由现金流 | 经营净现金流 − 购建固定资产等资本开支 | |
| 利息保障倍数 | (利润总额 + 利息费用) / 利息费用 | 有息负债高时必算 |
| 总资产周转率 | 营业收入 / 年末总资产 | |
| 应收周转天数 | 365 × 平均应收账款 / 营业收入 | 平均值用 (期初 + 期末) / 2，首年用期末 |
| 存货周转天数 | 365 × 平均存货 / 营业成本 | 同上 |
| 流动比率 | 流动资产 / 流动负债 | |
| 速动比率 | (流动资产 − 存货) / 流动负债 | |
| 资产负债率 | 总负债 / 总资产 | |
| 营收同比 | 本年营收 / 上年营收 − 1 | 首年为空 |
| 扣非归母净利润 | 归母净利润 − 非经常性损益 | 非经常性损益取年报披露值 |

## KPI 看板行清单（25～27 行，五年横排）

规模与利润：营业收入（亿元）、营收同比（%）、归母净利润（千万元）、
扣非归母净利润（千万元）、非经常性损益占归母净利（%）。

盈利与费用：归母净利率（%）、毛利率（%）、ROE（%）、销售费用率（%）、
管理费用率（%）、研发费用率（%）、期间费用率合计（%）。

税负：实际所得税率（%）、整体税负率（%）。

资本与偿债：资产负债率（%）、流动比率（倍）、速动比率（倍）、有息负债（亿元，
如披露）、利息保障倍数（倍）。

现金与营运：货币资金（亿元）、经营净现金流（亿元）、收现比（倍）、净现比（倍）、
总资产周转率（次）、应收周转天数（天）、存货周转天数（天）。

投入与回报：资本性支出（百万元）、简化自由现金流（百万元）、分红总额（百万元，
取自分红公告）、前五客户占比（%，取自年报前五大客户披露）。

单位换算：亿元 = 1e8 元，千万元 = 1e7 元，百万元 = 1e6 元。比率保留两位小数。

## 三表透视科目行（第四章）

- 利润表：营业总收入、营业成本、税金及附加、销售 / 管理 / 研发 / 财务费用、
  其他收益、投资收益、公允价值变动收益、信用减值损失、资产减值损失、营业利润、
  利润总额、所得税费用、净利润、归母净利润、扣非归母净利润、汇兑损益（如披露）。
- 资产负债表：货币资金、交易性金融资产、应收票据、应收账款、应收款项融资、
  合同资产、存货、流动资产合计、长期股权投资、固定资产、在建工程、无形资产、
  资产总计、短期借款、应付债券 / 可转债、应付账款、应交税费、流动负债合计、
  负债合计、归母权益。
- 现金流量表：销售收现、收到的税费返还、支付的各项税费、经营净流量、
  购建固定资产支付（资本开支）、投资净流量、筹资净流量、分配股利利润或偿付利息
  支付、收现比、经营净现金流 / 净利润。

## 预警阈值参考（制造业 / 一般工业经验值，写报告时结合行业调整）

| 指标 | 健康线 | 预警线 | 说明 |
| --- | --- | --- | --- |
| 收现比 | ≥1.0 | 连续两年 <0.85 且下行 | 跌破 0.7 为高危信号 |
| 净现比 | ≥0.8 | <0.5 | 利润与现金长期背离即预警 |
| 实际所得税率 | ≤法定税率 | 持续上行并突破法定税率 | 反推税盾浪费或不可扣除项 |
| 应收周转天数 | ≤75 天 | >100 天或同比 +20% | |
| 存货周转天数 | ≤100 天 | >150 天 | 结合减值计提看 |
| 资产负债率 | ≤50% | >65% 且快于行业 | |
| 前五客户占比 | ≤50% | >60% | |
| 非经常性损益占比 | ≤20% | 连续两年 >30% | 利润可持续性存疑 |
| 速动比率 | ≥1.0 | <0.8 | |
| 简化自由现金流 | 三年均值为正 | 连续两年为负且资本开支上行 | |

## 组合预警信号（出现即写入看板洞察）

1. 收入增长但扣非利润或现金流下降——盈利质量风险扩展。
2. 利润大增但经营现金流反降——收入现金质量恶化，查应收与票据。
3. 实际所得税率突破法定税率——税盾结构问题。
4. 资本开支连续上行 + 自由现金流转负 + 分红不减——资金缺口三重压力。
5. 毛利率修复但费用率同步上行——毛利改善被费用吞噬。
6. 税收优惠利润占比高 + 资格临近到期——政策依赖风险。

## 可比性提示（跨年分析必做）

- 会计政策变更：核对每个年度报表的准则解释执行情况（如解释第 18 号质保费用
  入营业成本并追溯调整、解释第 20 号金融资产分类）。受影响年度在表格下方标注
  「该年度毛利率不能与前后年度机械横比」。
- 合并范围变化：并购、处置子公司导致口径跳变的年份要标注。
- 期后数据（季报 / 半年报）未经审计，只做趋势观察，不进五年表。

## 行业特殊处理

银行、保险、券商不适用收现比、净现比与简化自由现金流。改看不良率、拨备覆盖率、
资本充足率、净息差。房地产看三道红线与现金短债比。本 skill 默认面向一般工商业；
金融地产标的先确认口径再套模板。
