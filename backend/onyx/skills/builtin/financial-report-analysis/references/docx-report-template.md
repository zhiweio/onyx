# 财报解读 · Word 报告契约

用 `docx` 技能（python-docx）把 `output_template.md` 的内容渲染成专业 Word 报告。
本契约约束「报告必须为真、必须包含」，不约束每章内部写法——内容依证据组织，
由 `output_template.md` 的章节脊柱引导。

## 交付物

`outputs/{公司名}_财报解读_{YYYY}Q{n}.docx`，与 HTML 报告（slideblocks 版）数据、
结论与图表清单完全一致。Word 图表是 `outputs/charts/` 的 PNG；HTML 图表由
`slideblocks` 内置渲染路径绘制。两份报告出自同一套 `outputs/analysis/` 数据。

## 文档结构（顺序固定，章节标题按内容自拟）

1. **封面**：报告标题「{公司全称}（{代码}）财报解读」、报告期、数据时点、
   币种、出具日期。不放内部路径与工具名。
2. **目录**：python-docx 插入 TOC 域，或手工列章节（与正文标题一致）。
3. **执行摘要**：半页以内。总评档位（健康/关注/预警）、三个最重要发现、
   一句话结论。读者只看这页也能拿到结论。
4. **正文**：沿用 `output_template.md` 的章节脊柱
   （财务健康度快照 → 分项诊断 → 读生意 → 业绩指引 → 综合结论）。
   每章开头一句判断，再摆证据；口径与量纲随数字注明。
5. **数据来源与方法**：读者版说明。数据源名称（公司定期报告 /
   同花顺（iFinD）/ 企查查 / 智慧芽 / 公开检索）、报告期口径、单季拆分方法、
   派生指标公式、未获取项清单。不写 MCP 工具名、服务器名、内部路径、脚本名。
6. **免责声明**：保留在文末。

## 必备产物

- 健康度快照表（1.1）与档位修正表（1.3），档位三档：健康/关注/预警。
- 季度明细表（1.2）：单季金额、单季比率、同比/环比，缺的期数留「未获取」。
- 异常扫描结论表（1.4）：命中项逐条列，未命中写「未发现显著异常背离」。
- 经营 KPI 快照与量价拆分（1.5）：口径声明必写。
- 图表不少于 8 张：全部来自 `outputs/charts/` 的 PNG，编号连续
  （图 1、图 2……），每图有图注与来源行（如「数据来源：公司 2025 年年报第 12 页」）。
- 每张表下有来源行，写法同上。

## 硬规则

- 每个数字按 SKILL.md 引用写法溯源：来源文件页码、原始来源名称（注明数据项）、
  或网页 URL + 访问日期，三选一。
- 正文不出现 MCP 工具名、服务器名、`outputs/`、`/tmp/` 等内部或临时路径、脚本名。
- 无 `{{占位符}}`，无「草稿 / 待修改 / 待补充 / TODO」等未定稿标记。
- 红涨绿跌（A股习惯）；健康度三档配色语义与 HTML 报告一致。
- 银行、保险、券商不套收现比与 FCF，改用行业口径并注明。

## 排版要求（python-docx）

- 标题层级：章 = Heading 1，节 = Heading 2；正文用统一正文字体与字号。
- 表格用内置网格样式，表头加粗；数字右对齐。
- 图：`add_picture`，宽度统一（约 15cm），图注居中小字。
- 页眉写报告标题，页脚写页码。封面无页眉。
