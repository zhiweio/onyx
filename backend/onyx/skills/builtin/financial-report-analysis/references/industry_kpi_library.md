# 行业与公司关键经营指标库（KPI）

> **定位**：财务指标是**结果**，经营指标是**原因**。只用毛利率、ROE 这类财务比率读财报，永远只能看到"变好了/变坏了"，看不到"为什么"。本文件提供按行业拆分的**经营指标清单**——它们是财务数字的上游变量，也是下一季度验证判断的**先行指标**。
>
> **与 `financial_health_criteria.md` 的分工**：后者给财务比率的阈值（毛利率、ROE、收现比…）；本文件给经营指标的口径与读法（ASP、单位净利、市占率、库存深度…）。两者要**交叉验证**：经营指标解释财务结果，财务指标检验经营指标有没有说谎（如销量↑但 OCF↓ → 压货）。
>
> **使用方式**：分析某家公司时，先定位它所属行业的章节，取该行业的**必看清单**；若行业不在库中，用第 0 节「五元组自建法」现场构造。**核心 KPI 控制在 3~6 个**，贪多会稀释焦点。

## 0. 通用方法：五元组自建指标（行业不在库里时用这个）

任何生意的经营表现，都可以拆成五个维度。按这个顺序问一遍，指标清单自然出来：

| 维度 | 问的问题 | 典型指标 | 直接映射的财务科目 |
|---|---|---|---|
| **量** | 卖出去多少？ | 销量、产量、装机量、用户数、单量、客流、产能 | 营业收入（分子） |
| **价** | 每个卖多少钱？ | ASP、客单价、单价、票价、费率、租金 | 营业收入 / 毛利率 |
| **结构** | 卖的是什么组合？ | 高端占比、新品占比、品类/区域/客户结构、集中度 | 毛利率、费用率 |
| **份额** | 相对对手如何？ | 市占率、渗透率、增速差（公司增速 − 行业增速） | 营收增速质量 |
| **单位经济** | 单个单位赚不赚钱？ | 单位毛利、单位净利、单位成本、单店/单客模型、LTV/CAC | 净利率、ROIC、FCF |

### 0.1 选取规则（硬要求）

1. **可季度化**：必须能拿到近 8 个季度的序列（否则无法做趋势诊断，只能当背景信息）。
2. **可核验**：优先公司公告 / 行业协会 / 监管披露；用研报估算值必须标注「估算」。
3. **口径一致**：同一指标跨期口径必须一致，变更时（如并表、统计范围调整）必须标注并做可比说明。
4. **能拆到单季**：销量、客单价这类流量指标天然是单季口径；装机量、市占率这类时点/存量指标不拆单季，标注「时点值」。
5. **3~6 个足够**：选最能解释这家公司利润变化的 3~6 个，其余放"次要跟踪"。

### 0.2 阈值怎么定（经营指标没有通用阈值）

经营指标没有"ROE ≥ 15%"这种通用标准，用三类基准叠加判定：

| 基准 | 做法 | 判定 |
|---|---|---|
| **自身轨道**（首要） | 建近 8 季序列，看斜率、连续同向期数、偏离均值 >2σ | 与 SKILL.md 第二节趋势规则完全一致 |
| **同业同期** | 与主要对手在同一季的**方向差**（不是绝对值差） | 对手↑我↓ = 份额在流失 |
| **行业总量** | 公司增速 − 行业增速 = 增速差 | >0 跑赢，<0 跑输（跑输而绝对增长，也是预警） |

### 0.3 经营指标与财务指标的桥接（背离即信号）

| 背离形态 | 含义 | 处置 |
|---|---|---|
| 量↑ + 单位净利↓ | 以价换量 / 降价促销 | 定「关注」，看是否换取了份额 |
| 量↑ + 营收↓ | ASP 崩塌（价格战或产品降级） | **预警** |
| 量↑ + 存货↑（快于量） | 压货，销量可能是批发口径堆渠道 | **预警**，对比终端销量（上险量/零售量） |
| 量↑ + OCF↓ | 利润没变成现金（账期放松 / 压货） | **预警** |
| 结构升级（高端占比↑）+ 毛利率↓ | 升级是假的，或高端产品也在降价 | **预警**，查分价格带 ASP |
| 份额↑ + 单位净利↓ | 烧钱换份额 | 关注，看单位经济能否随规模转正 |
| 单位成本↓ 慢于 ASP↓ | 规模效应跑不赢降价 | 预警，毛利率将继续承压 |

## 1. 汽车 / 新能源乘用车（比亚迪为详细范本）

### 1.1 必看指标清单

| 指标 | 口径 / 公式 | 数据来源 | 怎么读 |
|---|---|---|---|
| **总销量（辆，单季）** | 公司月度产销快报累加；分乘用车 / 商用车 | 公司公告、港交所/巨潮月报、乘联会 | 量的主口径；看单季 YoY 与 QoQ 序列 |
| **分品牌销量结构** | 王朝+海洋 / 腾势 / 方程豹 / 仰望 各品牌销量及占比 | 公司月报（比亚迪按品牌披露） | **高端化**的直接证据 |
| **高端车销量占比** | (腾势 + 仰望 + 方程豹) 销量 ÷ 总销量；或 ≥30 万元车型销量占比 | 月报 + 乘联会价格带数据 | 结构升级的核心指标，同时看**销量占比**和**收入占比**两个口径 |
| **单车均价 ASP（万元）** | 汽车业务分部收入 ÷ 汽车销量 | 财报分部收入 + 销量 | 价的主口径，见下方 1.2 口径陷阱 |
| **单车净利（元）** | 扣非归母净利 ÷ 总销量（趋势口径） | 财报 + 销量 | 单位经济核心；绝对值含非汽车业务须注明 |
| **单车毛利（元）** | (汽车分部收入 − 汽车分部成本) ÷ 销量；粗算用 营收×毛利率 ÷ 销量 | 财报 | 剔除费用后看产品本身盈利能力 |
| **单车成本（万元）** | 营业成本 ÷ 销量 | 财报 + 销量 | 规模效应的直接体现；与 ASP 做剪刀差 |
| **出口 / 海外销量占比** | 海外销量 ÷ 总销量；海外收入占比 | 公司月报、财报分地区 | 出口通常单车毛利更高，是利润结构的关键变量 |
| **国内新能源乘用车市占率** | 公司销量 ÷ 行业新能源乘用车销量 | 乘联会 / 中汽协 | 份额主口径；看**份额斜率**不看绝对值 |
| **批发 vs 终端（上险量）差** | 批发销量 − 同期交强险上险量 | 乘联会、交强险数据 | >0 且持续扩大 = 渠道压库，销量有水分 |
| **渠道库存深度（月）** | 渠道库存 ÷ 近 3 月均销量；行业看库存预警指数 | 中国汽车流通协会 | >1.5 个月警戒；配合降价促销看 |
| **单车三费（销售+管理+研发）/销量** | 期间费用 ÷ 销量 | 财报 | 规模摊薄是否跑赢降价 |
| **单车 Capex** | 购建固定资产等现金支出 ÷ 销量 | 现金流量表 | 扩张强度；转固后单车折旧会跳升 |
| **产能利用率** | 实际产量 ÷ 设计产能 | 年报/业绩会 | <70% 时单车折旧拖累毛利 |
| **应付账款周转天数 / CCC** | 见 financial_health_criteria 第 7 节 | 财报 | **重点红旗**：账期是否靠拉长供应链付款撑现金流 |
| **单车折旧摊销** | 折旧摊销 ÷ 销量 | 现金流量表附注 | 转固周期结束后单车成本应下降，不降反升要查 |

### 1.2 口径陷阱（必须标注）

- **ASP 口径**：比亚迪财报分部为「汽车、汽车相关产品及其他产品」与「手机部件、组装及其他产品」（后者为比亚迪电子）。前者**还包含二次充电电池、储能、光伏等非整车收入**，直接除销量会**高估 ASP**。
  - 实操：用「汽车分部收入 ÷ 总销量」做**趋势序列**（口径一致，趋势可比），但绝对值须与乘联会/公司交流口径交叉验证，并在报告中注明「含非整车业务，ASP 为趋势口径」。
  - 若有更纯的整车收入披露（年报分部附注），优先用纯口径。
- **单车净利口径**：归母净利包含手机部件（电子代工）业务利润，**绝对值不代表整车单车盈利**。作为**趋势指标**使用（口径一致则趋势有效），并在报告中写明。
- **销量口径**：公司月报多为**批发销量**（发给经销商/出口发运），不等于终端交付。必须对照上险量/零售量。
- **高端占比口径**：按品牌（腾势+仰望+方程豹）与按价格带（≥30 万）结果不同，两者都要看，避免"品牌高端但卖的是低价车型"。

### 1.3 量—价—利三角判定矩阵（汽车行业核心分析框架）

| 销量 | ASP | 单车净利 | 判定 | 说明 |
|---|---|---|---|---|
| ↑ | ↑ | ↑ | **健康** | 量价齐升，结构升级成功，最强形态 |
| ↑ | → | ↑ | **健康** | 成本下降驱动，规模效应兑现 |
| ↑ | ↓ | ↑ | **健康（观察）** | 降价但成本降更快，规模效应跑赢降价 |
| ↑ | ↓ | ↓ | **关注** | 以价换量；看份额是否同步提升（换到了才算值） |
| ↑ | ↓↓ | ↓↓ | **预警** | 价格战失血，量增不增利 |
| → | ↑ | ↑ | **健康（观察）** | 高端化驱动，需确认高端占比是否同步提升 |
| ↓ | ↑ | → | **关注** | 主动收缩保价（不一定坏），需看份额是否流失 |
| ↓ | ↓ | ↓ | **预警** | 量价利三杀，周期下行或竞争力衰退 |

### 1.4 比亚迪专属跟踪清单（最小集，每期必填）

| # | 指标 | 为什么必看 |
|---|---|---|
| 1 | 单季总销量 YoY / QoQ | 量的起点 |
| 2 | 单车均价 ASP（趋势口径） | 价格战的核心观测 |
| 3 | 单车净利（趋势口径） | 单位经济，规模效应 vs 降价的胜负手 |
| 4 | 高端车占比（品牌口径 + 价格带口径） | 高端化战略是否兑现 |
| 5 | 出口占比 | 高毛利业务的结构权重 |
| 6 | 国内新能源乘用车市占率 | 竞争格局位置 |
| 7 | 批发 vs 上险量缺口 | 销量成色，压库信号 |
| 8 | 应付账款周转天数 / CCC | 现金流质量的隐藏变量（供应链账期） |
| 9 | 单车 Capex 与单车折旧 | 下一轮成本曲线的先行指标 |

### 1.5 汽车行业常见红旗

- 批发销量增速 >> 上险量增速，且渠道库存深度连续 2 季上升 → **压货**，后续必然降价去库。
- 单车净利连续 3 季下滑但销量创新高 → **以价换量已到极限**，规模效应失效。
- 应付账款周转天数快速拉长（尤其配合供应链票据/反向保理）→ 现金流被"占用供应商"美化，属于**治理级关注项**。
- 单车 Capex 高企但产能利用率 <70% → 未来折旧压力，毛利率有下行风险。
- 高端占比（收入口径）提升但（销量口径）不提升 → 高端车型降价冲量，升级含金量存疑。
- 出口占比提升但海外单车净利下滑 → 可能是低价清库存或海外价格战。

## 2. 白酒 / 食品饮料

| 指标 | 口径 | 来源 | 读法 |
|---|---|---|---|
| 销量（吨，分产品） | 分高/中/低档酒销量 | 年报/半年报经营数据 | 量的主口径 |
| 吨价（万元/吨） | 酒类收入 ÷ 销量 | 财报 | 结构升级的核心度量 |
| 高档酒收入占比 | 高档酒收入 ÷ 酒类收入 | 财报 | 升级/降级方向 |
| **合同负债（预收款）** | 期末余额及同比 | 资产负债表 | **蓄水池**：大增=经销商打款积极；大降=渠道信心弱 |
| 经销商数量与单商收入 | 经销商数、平均单商打款 | 年报 | 渠道是在扩张还是收缩 |
| 批价（飞天/普五批价） | 渠道批发价 | 渠道调研、今日酒价 | 领先于报表的真实景气；批价与出厂价倒挂 = 危险 |
| 渠道库存（月） | 渠道库存月数 | 渠道调研 | >3 个月警戒 |
| 直销/团购占比 | 直销收入 ÷ 营收 | 财报 | 直销占比↑通常吨价与毛利↑ |

**红旗**：合同负债连续下降 + 应收票据大增（放宽打款条件换收入）；批价倒挂；经销商数量却在增加（招商压货）。

## 3. 消费电子 / 代工制造

| 指标 | 口径 | 读法 |
|---|---|---|
| 出货量（台/部，分品类） | 分产品出货 | 量的主口径 |
| ASP（元/台） | 分部收入 ÷ 出货量 | 产品升级 vs 降价 |
| 产能利用率 / 稼动率 | 实际 ÷ 设计 | <70% 毛利率承压 |
| 良率 | 良品率 | 良率爬坡期毛利率受压，成熟后释放 |
| 大客户集中度 | 前五大客户收入占比 | >50% 且单一客户 >30% = 依赖风险 |
| 单机价值量（元） | 单机中公司供货物料价值 | 在客户机型中的份额与升级空间 |
| 单位人工成本 / 自动化率 | 成本结构 | 成本竞争力 |

**红旗**：出货量↑ 但 ASP↓ 且毛利率↓（降价换单）；大客户订单转移传闻 + 存货同步上升。

## 4. 半导体 / 面板 / 元器件

| 指标 | 口径 | 读法 |
|---|---|---|
| 产能（万片/月，等效 8 寸） | 折合产能 | 供给端 |
| 稼动率 | 实际投片 ÷ 产能 | 面板/代工毛利率的第一驱动 |
| ASP（美元/片 或 元/片） | 收入 ÷ 出货 | 周期价格主指标 |
| 单位成本（元/片） | 成本 ÷ 出货 | 与 ASP 剪刀差 |
| 存货周转天数 | 时点序列 | 景气反向指标：去库存末期 = 底部 |
| 资本开支 / 营收 | Capex 强度 | 扩产节奏与下一轮周期的供给 |
| 国产化率 / 客户结构 | 内销占比、大客户占比 | 结构性而非周期性变量 |
| 制程/产品结构 | 先进制程或高端产品收入占比 | 技术升级兑现度 |

**红旗**：ASP 与稼动率同步下滑（量价齐跌）；存货高企同时 Capex 创新高（周期顶部扩产）。

## 5. 互联网平台（电商 / 本地生活 / 广告）

| 指标 | 口径 | 读法 |
|---|---|---|
| 活跃用户（MAU / DAU） | 单季平均或期末 | 用户盘子 |
| 用户时长 / 使用频次 | 人均单日时长 | 注意力份额 |
| GMV / 订单量 | 单季 | 交易规模 |
| **Take Rate（货币化率）** | 平台收入 ÷ GMV | 变现能力，与商家生态博弈 |
| 客单价 / 单均收入 | 收入 ÷ 订单 | 结构升级 |
| ARPU（元/用户） | 收入 ÷ 活跃用户 | 单用户价值 |
| 获客成本（营销费用 ÷ 新增用户） | 单季 | 与 ARPU 对比看回收周期 |
| 广告加载率 / 转化效率 | 平台侧 | 广告变现的天花板变量 |

**红旗**：GMV↑ 但 Take Rate↓（补贴换规模）；用户数↑ 但 ARPU↓（下沉稀释）；营销费用增速 >> 收入增速。

## 6. SaaS / 企业软件

| 指标 | 口径 | 读法 |
|---|---|---|
| ARR / 订阅收入 | 年化经常性收入 | 收入质量的锚 |
| NDR（净收入留存率） | 老客户收入留存净额比 | >110% 优秀，<100% 意味着流失大于扩张 |
| 客户数 / 大客户（ARR>百万）数 | 期末 | 客户结构 |
| 客单价 ARPA | ARR ÷ 客户数 | 升级/降级 |
| CAC 回收期（月） | 销售投入 ÷ 新增 ARR毛利 | <12 月优秀 |
| 续费率 / 流失率（Churn） | 年度 | 生意质量核心 |
| **合同负债 / 递延收入** | 期末余额及同比 | 收入的先行指标（Q4 验收型公司尤其重要） |
| 研发费用资本化率 | 资本化研发投入 ÷ 总投入 | 会计质量红旗 |

**红旗**：ARR↑ 但 NDR↓（靠新客补老客流失）；递延收入同比转负；研发资本化率突增（美化利润）。

## 7. 游戏 / 传媒

| 指标 | 口径 | 读法 |
|---|---|---|
| 流水（分产品） | 单季流水 | 收入先行（流水确认递延到收入） |
| **递延收入** | 期末余额 | 流水 → 收入的蓄水池 |
| MAU / DAU / 付费用户数 | 期末 | 用户盘子 |
| ARPPU（元/付费用户） | 收入 ÷ 付费用户 | 付费深度 |
| 付费率 | 付费用户 ÷ 活跃用户 | 变现广度 |
| 老游戏流水衰减率 | 同比 | 长线运营能力 |
| 新游储备 / 版号 | 数量与上线节奏 | 未来增长可见度 |
| 买量 ROI | 销售费用 ÷ 新增流水 | 投放效率 |

**红旗**：流水↓ 但收入↑（消耗递延收入，未来收入已透支）；老游戏衰减加速且无新游接力。

## 8. 医药 / 创新药 / CXO

| 指标 | 口径 | 读法 |
|---|---|---|
| 核心产品销售额（分品种） | 单季 | 放量曲线 |
| 医保谈判降价幅度 | 事件 | 价的断崖变量 |
| 集采中标/落标情况 | 事件 | 量的变量 |
| 研发投入与资本化率 | 单季 | 会计质量 |
| 在研管线（临床阶段分布） | 期末 | 未来价值 |
| 医院/终端覆盖数 | 期末 | 渠道渗透 |
| CXO：在手订单 / 新签订单 | 期末 | 收入先行指标（2~3 年可见度） |
| CXO：产能与利用率 | 期末 | 交付能力 |

**红旗**：核心品种进入集采且无新品种接力；在手订单连续 2 季下滑；研发资本化率突增。

## 9. 银行 / 保险 / 券商

> 这类公司的"经营指标"就是监管口径的核心指标，财务比率（OCF/收现比）不适用。

| 子行业 | 指标 |
|---|---|
| 银行 | 净息差 NIM、生息资产增速、不良率、拨备覆盖率、拨贷比、核心一级资本充足率、RORWA、存贷比、信用成本 |
| 保险 | **NBV（新业务价值）**、新单保费、代理人数量与人均产能、13/25 个月继续率、综合成本率（财险）、综合投资收益率、偿付能力充足率、EV（内含价值） |
| 券商 | 股基成交额市占率、两融余额市占率、IPO/再融资承销规模与排名、资管 AUM、自营收益率、风险覆盖率 |

**红旗**：不良率下降但同时拨备覆盖率下降（少提拨备美化利润）；NBV 增长靠假设调整；券商市占率下滑但收入靠自营。

## 10. 房地产 / 建材 / 工程机械

| 子行业 | 指标 |
|---|---|
| 地产 | 销售额/面积（单月+累计）、权益销售比例、拿地金额/销售金额比、土储去化周期、已售未结（合同负债）、平均融资成本、三道红线指标、交付面积 |
| 水泥/建材 | 吨价、吨毛利、出货量、产能利用率、库容比、区域需求（基建/地产开工） |
| 工程机械 | 分产品销量、开工小时数（挖掘机指数）、市占率、出口占比、二手机残值率、应收账款逾期率 |

**红旗**：销售额↓ 但拿地强度↑（现金流错配）；表内负债降但表外/明股实债增；吨价与出货同步下滑。

## 11. 零售 / 餐饮 / 免税

| 指标 | 口径 | 读法 |
|---|---|---|
| 门店数（净开店） | 期末 | 扩张节奏 |
| **同店销售 SSSG** | 可比门店同比 | 剔除开店后的内生增长，最重要 |
| 单店模型 | 单店营收/坪效/投资回收期 | 新店是否盈利 |
| 客单价 / 客流量 | 单季 | 拆 SSSG 的驱动 |
| 会员数 / 复购率 | 期末 | 用户黏性 |
| 存货周转天数 | 时点序列 | 服装尤其关键 |
| 免税：离岛免税购物人次与客单价 | 单月 | 政策敏感 |

**红旗**：营收增长全靠开店但同店负增长（开店不可持续）；存货周转天数连续上升；单店回收期拉长。

## 12. 快递物流 / 航空

| 子行业 | 指标 |
|---|---|
| 快递 | 单量（件，单月）、单票收入（元）、单票成本、市占率、单票净利、末端派费、资本开支/单量 |
| 航空 | ASK（可用座公里）、RPK（收入客公里）、客座率、单位收益（RASK）、单位成本（CASK）、油价与汇兑敏感性、机队引进计划 |
| 航运 | 运价指数（BDI/CCFI/SCFI）、运力投放 TEU、单箱成本 |

**红旗**（快递）：单量↑ 但单票收入↓ 且单票成本降不动 → 价格战失血；单量份额↑ 但单票净利连续 3 季下滑（以价换量）。

## 13. 光伏 / 锂电 / 新能源材料

| 指标 | 口径 | 读法 |
|---|---|---|
| 出货量（GW / GWh / 万吨） | 单季 | 量 |
| 单位售价（元/W、元/Wh、万元/吨） | 收入 ÷ 出货 | **周期价格的主指标** |
| 单位毛利 / 单位净利 | 毛利 ÷ 出货 | 单位经济，判断产能是否过剩 |
| 产能与产能利用率 | 期末 | 供需格局 |
| 行业排产 / 开工率 | 月度 | 景气同步指标 |
| 库存（含硅料/电池库存） | 期末 | 去库/累库周期位置 |
| 原材料成本（硅料/碳酸锂价格） | 现货价 | 成本端传导 |
| 一体化率 / 自供比例 | 结构 | 抗周期能力 |
| 新技术占比（TOPCon/BC/固态） | 结构 | 技术代际风险 |

**红旗**：单位净利转负但仍在扩产（行业出清未到）；出货↑ 但单位售价↓ 幅度更大 → 增收不增利；库存与应收同步暴增。

|---|---|---|

## 15. 周期（化工 / 有色 / 钢铁 / 煤炭 / 航运）

| 指标 | 口径 | 读法 |
|---|---|---|
| 产品价差（价格 − 原料成本） | 单季，如吨毛利 | **周期位置的第一指标**，比价格本身更准 |
| 开工率 / 行业开工率 | 月度 | 供需松紧 |
| 行业库存（社会库存） | 月度 | 补库/去库周期位置 |
| 单位完全成本与行业成本曲线位置 | 比较 | 护城河：是否在成本曲线左侧 |
| 新增产能投放节奏 | 事件 | 未来供给冲击 |
| 长协/现货比例 | 结构 | 盈利稳定性 |
| 周期底部 FCF | 现金流 | 能否活过谷底 |

**红旗**：价差处于历史高位时 ROE 创新高 → 周期顶部（此时高 ROE 是卖出信号而非买入信号）；高盈利期大幅扩产。

## 16. 把 KPI 接进季度序列（操作要点）

1. **录入**：把手工收集的经营指标按季录入 JSON/CSV，用 `scripts/operating_kpi.py` 统一计算同比、环比、派生指标与趋势特征（避免手算错误）。
2. **对齐**：经营指标的报告期须与财报期**一一对齐**（如 2026Q2 的 ASP = 2026Q2 汽车分部收入 ÷ 2026Q2 销量）。
3. **派生指标用公式定义**：ASP、单车净利、占比这类派生值一律在脚本里用公式算，不手填，保证可复算。
4. **与财务序列同表呈现**：经营指标序列与财务序列放同一时间轴，便于直接看背离（见 0.3）。
5. **缺失处理**：某季无数据填 `null`，脚本输出「—」，严禁插值或臆造。

## 附：常见数据来源

| 数据 | 来源 |
|---|---|
| 销量、产量、经营数据 | 公司月度/季度经营数据公告（巨潮、港交所）、投资者关系官网 |
| 行业销量、市占率 | 乘联会、中汽协、中国汽车流通协会、国家统计局 |
| 上险量（终端） | 交强险上险数据（第三方数据商） |
| 批价、渠道库存 | 渠道调研、第三方价格监测（如今日酒价） |
| 行业景气/排产 | 行业协会月报、第三方咨询（如 InfoLink、SMM、百川盈孚） |
| 宏观需求代理 | 国家统计局、央行；未连接终端时用 websearch / webfetch + 官方统计公报 |
| 业绩会披露的经营数据 | 业绩说明会纪要（管理层常直接披露销量结构、ASP、产能利用率） |

> 所有数据须可核验；拿不到就标「未获取」，严禁臆造或用研报估算值冒充实际值。研报估算须显式标注「估算」。
