# 季度明细数据与趋势诊断

本文件为「财务健康度快照」提供**季度序列**的获取、拆算与趋势判定方法。单点数据只能说明"现在是好是坏"，季度序列才能说明"在变好还是变坏"——后者才是诊断的核心。

---

## 1. 为什么必须看季度序列

| 单点（本期数） | 季度序列（近 8 季） |
|---|---|
| 只能判断当期水平是否达标 | 能判断方向、斜率、波动、拐点 |
| 易被季节性/一次性因素误导 | 可识别一次性扰动与趋势性变化 |
| 异常是"看起来不对" | 异常是"偏离了自己的历史轨道" |
| 无法区分周期顶点与成长中段 | 可定位景气位置（加速 / 见顶 / 触底） |

**核心原则**：健康度判定 = **水平**（当期值 vs 阈值）+ **趋势**（序列方向 vs 自身轨道）。两者冲突时以趋势为准——当期漂亮但连续 3 季恶化的指标，定「关注」而非「健康」。

## 2. 数据获取：同花顺 HiThink 或上传件

### 2.1 调用方式

优先走 `hithink-finance` / `hithink-a-share` 取近 8 季以上财务（拆累计首季须再多 4 期）。
用户上传 PDF / Excel / 图片时，先 `document-ingest`，再写成
`outputs/analysis/statements.json`，用 `scripts/normalize_statements.py`
转成 `quarterly_trend.py` 的 `{income, balance, cashflow}` 行表。

脚本仍兼容 `{income:[...], balance:[...], cashflow:[...]}` 或单表行列表。
每行用 `EndDate`（`YYYY-MM-DD`）。字段名见 2.2。

### 2.2 A 股 / 港股字段映射（实测差异极大，勿混用）

| 含义 | A 股 | 港股 |
|---|---|---|
| 营业收入（累计） | `OperatingRevenue` | `OperatingIncome` |
| 营业总收入（累计） | `TotalOperatingRevenue` | — |
| 归母净利（累计） | `NPParentCompanyOwners` | `ProfitToShareholders` |
| 扣非归母（累计） | `NPDeductNonRecurringPL` | —（港股无扣非，用 `EarningAfterTax` 或 Non-IFRS 调整项，须注明口径） |
| 税后利润 | `TotalProfit`（利润总额） | `EarningAfterTax` |
| 毛利率（累计） | `GrossIncomeRatio` | `GrossIncomeRatio` |
| 净利率（累计） | `NetProfitRatio`（净利含少数股东 ÷ 营业收入） | `NetProfitRatio` |
| ROE（累计期） | `ROE` / `ROEWeighted` / `ROECut` | `RoeWeighted` |
| ROIC（累计期） | `ROIC` | — |
| 经营现金流（累计） | `NetOperateCashFlow` | `CFO` |
| 销售收现（累计） | `GoodsSaleServiceRenderCash` | —（**港股收现比不可算，须标注未获取**） |
| 资产负债率 | `DebtAssetsRatio`（在 balance） | `DebtAssetsRatio`（在 income，注意位置不同） |
| 归母净资产 | `SEWithoutMI` | `SeWithoutMinority` |
| 货币资金 | `CashEquivalents` | `Cash` |
| 有息负债 | `InterestBearDebt` | — |
| 存货 / 应收相关 | `Inventories`、`BillAccReceivable`、`ContractLiability`、`NotAccountsPayable`（**需 `fields=all`**） | — |
| 周转率（累计期） | `ARTRate`、`InventoryTRate`、`TotalAssetTRate` | — |
| TTM 字段 | `OperatingRevenueTTM`、`NPParentCompanyOwnersTTM`、`NetOperateCashFlowTTM`、`ROETTM`、`EPSTTM`、`GrossProfitTTM`、`DividendTTM` | **无 TTM 字段**，须自算 |
| 同比字段 | 见 2.3 | `OperatingRevenueGr1y`、`NpParentCompanyGr1y`、`OperatingRevenueGr3y`、`NpParentCompanyGr3y` |
| 币种 | 人民币（元） | `CurrencyType` 字段标注（港币/美元），**换算与对比须注明** |

### 2.3 A 股增速字段语义（实测校准，勿用错）

| 字段 | 含义 |
|---|---|
| `TORGrowRate` | 营业总收入**累计**同比 |
| `TORGrowRate_Q` | 营业总收入**单季**同比 |
| `OperatingRevenueGrowRate_Q` | 营业收入**单季**同比 |
| `NPParentCompanyYOY` | 归母净利**累计**同比 |
| `NPParentCompanyYOY_Q` | 归母净利**单季**同比 |
| `NPParentCompanyCutYOY_Q` | 扣非归母**单季**同比 |

> 规则：带 `_Q` 后缀 = 单季口径；不带 = 累计口径。**拿累计增速当单季增速读，是财报分析最高频的错误之一。**

## 3. 口径校准：累计 → 单季（最关键的一步）

A 股与港股的定期报告均为**年初至今累计口径**（Q1 报 = 1~3 月，半年报 = 1~6 月，三季报 = 1~9 月，年报 = 全年）。直接把半年报数字当"二季度数字"会系统性高估。

### 3.1 拆算公式

设同一财年内按时间升序的各期累计值为 $C_1, C_2, ... C_n$：

$$Q_1 = C_1,\quad Q_i = C_i - C_{i-1}\ (i \ge 2)$$

- 比率类指标（毛利率、费用率）**不能相减**，须还原为分子分母再算：
  单季毛利率 = $(C_i \times GM_i - C_{i-1} \times GM_{i-1}) \div (C_i - C_{i-1})$
- 时点类指标（资产负债率、货币资金、有息负债、存货余额）**不拆单季**，直接按期末时点取数，跨期比较。
- **周转率类指标（ARTRate / InventoryTRate / TotalAssetTRate）是"累计期周转率"**，Q1 的分母期短，天然远低于全年值（茅台 Q1 应收周转率 3084 vs 半年 57047）。**禁止跨季度横向比较，只能同比同期比较（Q1 vs Q1，H1 vs H1）**，或用 TTM 口径自算。

### 3.2 TTM（滚动 12 个月）

- **优先用官方 TTM 字段**（A 股有）：`OperatingRevenueTTM`、`NPParentCompanyOwnersTTM`、`NetOperateCashFlowTTM`、`ROETTM`。
- 需要自算时：$TTM_t = \sum_{k=t-3}^{t} Q_k$（近 4 个单季之和）。
- 港股无 TTM 字段，一律自算。
- **校验**：自算 TTM 与官方 TTM 差异 >2% 时，说明单季拆算或财年分组有误，须回头检查（脚本已自动比对并告警）。

### 3.3 财年非自然年的处理

微软（6 月年结）、部分港股（3 月年结）、苹果（9 月年结）等，拆单季时须按**财年**分组而非日历年。分组规则：设财年结束月为 $m$，则日期 $d$ 所属财年 = $d.year$（若 $d.month \le m$）否则 $d.year + 1$。脚本用 `--fy-end` 指定。

## 4. 季度明细表：必取指标清单

近 8 季（不足则按实际期数，注明），按单季口径列示：

**绝对值类（单季）**：营业收入、归母净利润、扣非归母净利润、经营现金流净额、销售商品收到现金、资本开支（可得时）。

**比率类（单季）**：毛利率、净利率（单季归母 ÷ 单季营收）、收现比（单季收现 ÷ 单季营收）、扣非/归母（主业成色）。

**TTM 类**：营收 TTM、归母 TTM、OCF TTM、ROE TTM、FCF TTM（OCF TTM − Capex TTM）。

**时点类（期末）**：资产负债率、有息负债、货币资金、存货余额、合同负债（预收，景气前瞻指标）。

**周转类（同比同期比）**：应收周转率、存货周转率、总资产周转率 —— 只做 YoY 同期对比。

## 5. 趋势诊断五看法

对每个核心指标，按以下五步判定，**不只看当期值**：

1. **看方向**：近 4 季线性回归斜率（相对近 4 季均值的年化变化率）。> +5%/年 为改善，±5% 内为平稳，< −5%/年 为恶化。
2. **看连续**：从最近一期往前数，同向变化连续了几期。**同向连续 ≥3 期 = 趋势确立**（无论当期绝对值多漂亮）。
3. **看波动**：变异系数 $CV = \sigma / \mu$（近 8 季）。CV < 0.15 平稳；0.15~0.30 波动；> 0.30 高波动（周期股/项目制收入属正常，须结合行业判断，不可一律判差）。
4. **看拐点**：斜率符号是否发生反转（由正转负 / 由负转正）。拐点须追因——是行业景气切换、公司战略调整，还是一次性因素（并表、处置、会计政策变更）。
5. **看背离**：指标之间的序列是否分道扬镳。核心背离对：
   - 营收序列 ↑ 但 应收周转序列 ↓ → 赊销换收入
   - 净利序列 ↑ 但 OCF 序列 ↓ → 纸面利润
   - 归母序列 ↑ 但 扣非序列走平 → 非经常性撑业绩
   - 存货序列 ↑ 但 营收序列走平/↓ → 滞销积压前兆
   - 毛利率序列 ↓ 但 存货序列 ↑ → 后续大概率计提减值

### 5.1 趋势档位判定（在水平判定基础上叠加修正）

| 情形 | 档位 | 说明 |
|---|---|---|
| 水平达标 + 趋势平稳或向上 + CV 低 | **健康** | 确定性最好 |
| 水平达标 + 连续 2 季同向恶化 | **健康（趋势转弱）** | 数值仍达标，但须在报告中点名下行的起点与原因 |
| 水平达标 + 连续 ≥3 季同向恶化 | **关注** | 趋势优先于水平，向下要打折 |
| 水平未达标 + 趋势向上且已连续 ≥2 季改善 | **关注（改善中）** | 不急判预警，给改善一个确认期 |
| 水平未达标 + 趋势走平或继续恶化 | **预警** | — |
| 任一期突然跳变（偏离近 8 季均值 >2σ）且无一次性事件解释 | **预警** | 触发异常追因流程（见 SKILL.md 第二节） |
| 序列中现金类指标（OCF/收现比）连续 2 季劣于净利序列 | **关注→预警** | 利润含金量存疑 |

## 6. 季节性处理

QoQ 环比在强季节性行业**不能直接读**，必须先做季节性对照：

- **消费/白酒**：Q1+Q4 旺季（春节、备货），Q2/Q3 淡季。看 Q1 的 QoQ 大降是正常的。
- **零售/电商**：Q4（双 11/双 12）、Q2（618）为峰。
- **地产/建材/家具**：Q4 竣工交付集中。
- **软件/To B**：Q4 收入确认集中（签单与验收节奏）。
- **教育**：Q3（暑期）为峰。
- **医药**：受集采招标节奏影响，季节性弱但政策扰动强。

处理方式二选一：
1. **优先用 YoY（同季对去年同季）**——天然剔除季节性，是趋势判断的主口径。
2. 必须看 QoQ 时，与**去年同期的 QoQ** 对照（如今年 Q2 环比 vs 去年 Q2 环比），或注明"该行业 Q2 为淡季，环比下滑属季节性"。

## 7. 常见陷阱（逐条核对，避免错误结论）

1. **累计当单季**：最高频错误。见 3.1。
2. **跨季度比周转率**：周转率是累计期口径，Q1 天然低。见 3.1。
3. **跨季度比 ROE / ROIC**：二者均为累计期口径（茅台 H1 ROE 17.7% vs 全年 33.6%）。跨期比较必须用 `ROETTM` 或年化处理。
4. **并表扰动**：并购并表会让序列在某一期"跳台阶"。须标注并表时点，并对可比口径（organic）做说明，否则趋势判断失真。
5. **会计政策变更 / 重述**：同一期数据在不同报告期可能被重述（如新收入准则、租赁准则）。发现历史数据"整段平移"时，检查 `InfoPublDate` 与是否发生重述。
6. **汇率**：港股/美股以外币披露，序列受汇率扰动。须注明币种与当期汇率，必要时说明"剔除汇率影响后"。
7. **股本变动影响每股指标**：回购/增发会扰动 EPS、BVPS。看回报率用 ROE/ROIC，不单看 EPS 序列。
8. **非经常性损益**：单季扣非/归母 < 80% 的季度要单独标出，判断利润的"真"部分趋势。
9. **期间长度不一**：53 周财年（部分零售/美股）、闰年，会造成单季轻微不可比。
10. **数据缺口**：港股无扣非、无销售收现、无 TTM 字段；A 股 `core` 窄表无存货/应收绝对额。**缺口一律标注「未获取」，不臆造、不用代理指标硬套。**

## 8. 降级策略

| 情况 | 处理 |
|---|---|
| 季度数 < 4（如港股仅半年报、新股） | 改用**半年度序列**，并在报告中注明"序列长度不足，趋势判定置信度低" |
| 仅有年报 | 放弃季度趋势，退化为年度序列（近 5 年），并明确说明 |
| 港股无扣非/收现比 | 用税后利润与 CFO 替代，注明口径差异 |
| 官方 TTM 与自算 TTM 不符 | 以官方 TTM 为准，并排查拆算错误（脚本会自动告警） |

## 9. 工具脚本

`scripts/quarterly_trend.py` 自动完成「累计→单季拆算 + YoY/QoQ + TTM + 趋势特征 + Markdown 出表」，避免每次手算出错。

```bash
# A 股（默认自然年财年）
python3 scripts/quarterly_trend.py --input sh600519.json --market A --quarters 8

# 港股（无扣非/收现比，自动降级）
python3 scripts/quarterly_trend.py --input hk00700.json --market HK --quarters 8

# 非自然年财年（如微软 6 月年结）
python3 scripts/quarterly_trend.py --input msft.json --market US --fy-end 6

# 输出 JSON 供二次处理
python3 scripts/quarterly_trend.py --input data.json --out json
```

输入为 `data_finance` 的原始返回体（存成 JSON 文件即可，脚本自动定位 income/balance/cashflow）。
脚本输出：① 单季明细表（Markdown）② TTM 表 ③ 趋势特征表（方向/连续期数/斜率/CV）④ 异常与口径告警。

> 脚本只输出**趋势特征与告警**，最终「健康 / 关注 / 预警」定档由分析者结合本文件第 5 节与行业属性判断——脚本不做投资判断。
