# 财务健康度判定标准

本文件为「维度一：基本财务数据」与「维度二：生意质量」提供健康度判定的通用基准。绝对阈值需结合行业属性调整（见结尾行业提示）。

> **配套文件**：本文件只覆盖**财务比率**；**行业与公司关键经营指标（KPI）** 见第 10 节（判定原则）与 **`industry_kpi_library.md`**（分行业指标清单、口径陷阱、行业红旗）。两者必须一起用——财务指标是结果，经营指标是原因。

> **与 `quarterly_trend_analysis.md` 的分工**：本文件给的是**水平阈值**（当期值达不达标）；季度趋势文件给的是**趋势判定**（在变好还是变坏）与**口径校准**（累计→单季、TTM、季节性）。最终档位 = 水平判定 + 趋势修正，修正规则见 SKILL.md 第二节第 4 点。**用本文件的阈值前，先确认数值已是单季或 TTM 口径。**

---

## 1. 增长（营收 / 利润）

- **健康**：营收 YoY ≥ 行业增速且为正；净利增速 ≥ 营收增速（盈利质量提升）或至少同向。
- **关注**：营收微增/持平、增收不增利（成本或费用拖累）。
- **预警**：营收连续两季负增长；或净利增速显著低于营收（毛利挤压 / 费用失控）。
- 必查：单季 vs 累计、YoY vs QoQ、是否含并表或一次性因素（如大额资产处置）。

## 2. 毛利率

- **健康**：毛利率稳定或提升，且处于行业前 1/2。
- **关注**：毛利率同比下滑 1~3pct 且有合理解释（价格战 / 成本上升）。
- **预警**：毛利率同比下滑 >3pct 且无改善迹象，或显著低于同业。
- 重点看趋势而非单点：连续下滑比单季波动更危险。

## 3. 净利率

- **健康**：净利率稳定/提升，扣非净利与归母净利接近（非经常性损益小）。
- **关注**：净利率下滑但毛利率稳定 → 费用率上升（销售/管理/研发）。
- **预警**：扣非/归母 < 80%（利润依赖非经常性）；或净利率转负。
- 必查：非经常性损益构成（政府补助、处置资产、公允价值变动、长期股权投资损益）。**警惕 GAAP 净利被一次性投资收益大幅扭曲**（如谷歌 Q2 净利 +298% 源于 $99B 股权纸面收益）。

## 4. 回报率：ROE / ROIC（巴菲特第一指标）

- **健康**：ROE ≥ 15% 且连续 3~5 年稳定；ROIC 显著高于 WACC（通常 > 10% 且 > 行业）。
- **关注**：ROE 在 8%~15%，或波动大；ROIC 仅略高于 WACC。
- **预警**：ROE < 8% 或连续下滑；ROIC < WACC（毁灭价值）；高 ROE 靠高杠杆堆出（负债率 >70% 仍高 ROE，脆弱）。
- **必做拆解**：ROE 的来源——是高净利率（好生意）、高周转（运营强）、还是高杠杆（脆弱）。高杠杆型高 ROE 要打折看。
- 银行/保险：ROE 仍看，但 ROIC 口径不同，看 RORWA / 综合成本率。

## 5. 现金流真实性（收现比 / 净现比 / 自由现金流）

### 5.1 收现比（营收现金含量）
- 收现比 = 销售商品、提供劳务收到的现金 ÷ 营业收入。
- **健康**：≥ 1.0（营收基本都收回钱）；长期 ≥ 0.95。
- **关注**：0.85~0.95，需解释（票据/应收占用、渠道压货）。
- **预警**：< 0.85 且持续，营收含金量存疑（透支信用 / 虚增）。

### 5.2 净现比（OCF / 净利润）
- **健康**：≥ 1（长期），且 OCF 与净利同趋势。
- **关注**：0.7~1.0，需解释（应收/存货占用）。
- **预警**：< 0.5 或 OCF 为负而净利为正（典型「纸面利润」）。

### 5.3 自由现金流 FCF
- FCF = 经营现金流净额 − 资本开支。
- **健康**：FCF 长期为正且覆盖净利润（真金白银）。
- **关注**：FCF 为负但属战略投入期（AI/扩张），且 Capex 有清晰回报路径。
- **预警**：FCF 长期为负且无回报可见性；或 FCF 依赖削减维护性 Capex 维持（损害未来）。

> 银行/保险/券商：经营现金流、收现比、FCF 口径不同，**不适用**（见行业提示）。

## 6. 资产负债率 / 偿债

- **健康**：资产负债率处于行业合理区间（制造业通常 <60%，轻资产 <40%），有息负债率低，利息保障倍数高。
- **关注**：负债率同比上升但可控，或短债占比偏高。
- **预警**：资产负债率 >70% 且现金流紧张；或存在「存贷双高」、高质押、大额商誉等治理红旗。
- 必查：有息负债规模、货币资金覆盖倍数、流动比率/速动比率、有息负债/EBITDA。

## 7. 营运资本与周转（标准化）

- **应收账款周转**：显著变慢 = 放宽信用促收入（质量差）；应收增速 >> 营收增速是红旗。
- **存货周转**：显著变慢 = 滞销/跌价；存货增速 >> 营收增速是积压信号。
- **应付账款周转**：拉长占用供应商 = 议价权强（正面）或资金紧张（负面），需结合现金流判断。
- **现金循环周期（CCC）**：越短越好；为负（如零售/科技预收）是强议价权体现。

## 8. 会计质量红旗（独立判定项）

- **非经常性损益**：扣非/归母 < 80% → 利润依赖一次性（处置资产、公允价值变动、政府补助、股权收益）。
- **折旧/摊销政策**：是否激进延长折旧年限（美化利润）；研发费用资本化比例异常高。
- **商誉**：商誉/净资产 > 30% 或大额减值风险；并购驱动增长需警惕。
- **关联交易**：大额关联交易、其他应收异常。
- **收入确认**：提前确认、经销压货、完工百分比激进。
- **治理级红旗**：存贷双高、高质押、审计师变更 / 保留意见。

## 9. 分部业务结构（增长引擎识别）

- **健康**：主力业务高毛利且稳健，新引擎增速 > 整体，利润池清晰。
- **关注**：增长依赖低毛利/收缩业务；分部利润率普遍下滑。
- **预警**：核心利润池萎缩且无接力业务；分部间大额内部抵消掩盖问题。

## 10. 行业与公司关键经营指标（KPI）

> 第 1~9 节给的是**财务比率**的阈值（结果）；本节给的是**经营指标**的判定原则（原因）。
> 完整行业清单、口径陷阱、行业红旗见 **`industry_kpi_library.md`**。

### 10.1 判定原则：经营指标没有通用阈值

经营指标（销量、ASP、市占率、单车净利、NDR…）**不存在"ASP ≥ X 万元就健康"这种通用标准**。用三类基准叠加判定：

| 基准 | 做法 | 判定 |
|---|---|---|
| **自身轨道**（首要） | 建近 8 季序列：斜率、连续同向期数、偏离均值 >2σ | 与 SKILL.md 第二节趋势规则同构 |
| **同业同期方向差** | 与主要对手在同一季的**方向差**，不是绝对值差 | 对手↑我↓ = 竞争力/份额在流失 |
| **行业总量（份额）** | 公司增速 − 行业增速 = 增速差 | >0 跑赢；<0 跑输（**跑输但绝对增长也是关注项**） |

### 10.2 三档判定（套用本文健康/关注/预警语义）

| 档位 | 判据 |
|---|---|
| **健康** | 核心 KPI 趋势向上或平稳，量价利三者同向或单位经济随规模改善；份额与同业方向差不落后 |
| **关注** | 量↑但单位经济↓（以价换量）；或份额↑但单位经济↓（烧钱换份额）；或核心 KPI 连续 2 季同向恶化 |
| **预警** | 核心 KPI 连续 ≥3 季同向恶化；或出现「量↑+营收↓」「量↑+存货↑」「量↑+OCF↓」「结构升级+毛利率↓」任一背离；或跑输行业增速 |

### 10.3 判定顺序（不要跳步）

1. 先判**量**（销量/用户数/出货量的方向）——没有量，价与结构都不成立。
2. 再判**价**（ASP/客单价/吨价）——价格是竞争烈度的体温计。
3. 再判**结构**（高端占比/品类占比）——区分"真升级"与"降价冲量"。
4. 再判**单位经济**（单位毛利/单位净利）——**这是最终裁决**：量价结构再好看，单位经济恶化就是价值毁灭。
5. 最后判**份额**——确认是行业性下滑还是公司竞争力下滑。

### 10.4 与财务比率的交叉验证（必做）

财务比率与经营指标**必须互证**，任一方向单独成立都要打问号：

| 财务表现 | 须用经营指标确认 | 若经营指标相反 |
|---|---|---|
| 毛利率提升 | 价↑ 或 单位成本↓ | 成本降幅靠会计处理（折旧年限/资本化）→ 会计质量红旗 |
| 营收增长 | 量↑ 且 价稳 | 价崩塌 → 增长不可持续 |
| 净利增长 | 单位净利↑ | 单位净利↓ → 靠非经常性/一次性 |
| 现金流改善 | 销量转化为回款（量↑ 且 应收周转不恶化） | 靠拉长应付账期 → 治理级关注 |
| ROE 高企 | 单位经济好 且 周转不恶化 | 靠杠杆或涨价不可持续 → 打折 |

### 10.5 数据口径硬要求

- 经营指标的报告期**必须与财报期一一对齐**（2026Q2 的 ASP = 2026Q2 分部收入 ÷ 2026Q2 销量）。
- 派生指标（ASP、单位净利、占比）一律用公式计算，不手填（用 `scripts/operating_kpi.py`）。
- **口径必须标注**：批发口径 vs 终端口径、含不含非主业收入、品牌口径 vs 价格带口径。
- 缺失填「未获取」，严禁插值、严禁把年度值拆成季度值。

## 行业提示

- **银行/保险/券商**：不能用 OCF/收现比/FCF 测利润真实性（客户存款即经营现金流入）；看不良率、拨备覆盖、资本充足率、净息差、RORWA。ROE 仍看但口径特殊。**其"经营指标"即监管口径核心指标，见 `industry_kpi_library.md` 第 9 节**（NIM、NBV、综合成本率、市占率等）。
- **房地产/基建**：高负债率常态，重点看经营性现金流、合同负债、融资成本。
- **科技/医药（高研发）**：短期净利率低正常，看研发费用资本化比例、管线/产品周期；FCF 短期为负属战略投入，重点看 Capex 回报路径。
- **周期股（有色/化工/航运）**：盈利波动大，看景气位置、自由现金流在周期低谷的表现；ROE 高时警惕周期顶部。
- **消费/食品**：看毛利率稳定性、渠道库存、预收款（合同负债）、收现比。
