# 财报解读报告 · 内容规范

> **本文件与 HTML 模板的分工（重要）**
> - **本文件** = 内容规范：定义报告的章节顺序、每节写什么、每张表填哪些行、判定口径。

## 二、分项诊断

> 每节都要 **先说趋势（近 8 季序列怎么走、拐点在哪一季），再说当期**；只用当期数字做解释的分析视为未完成。

### 2.1 增长
（营收/利润增速的**季度序列走势**：单季 YoY 连续几季为正/负、拐点在哪季；是否含一次性因素（并表/处置）；累计 vs 单季口径是否一致；趋势判断：单季 vs 累计、YoY vs QoQ）

### 2.2 盈利能力（毛利 / 净利）
（毛利率、净利率的**逐季轨迹**与变动原因：价格、成本、费用结构、产品结构；非经常性损益对净利的扭曲程度，扣非 vs 归母的**逐季缺口**）

### 2.3 现金流真实性
（收现比、净现比 OCF/净利、自由现金流 FCF 的**逐季序列**；是否出现"净利序列向上、现金序列向下"的背离；FCF 是否为正、是否被战略 Capex 吞噬）

### 2.4 偿债与资产结构
（负债率、有息负债、货币资金覆盖、有息负债/EBITDA 的**时点序列变化**；是否存在治理红旗：存贷双高/高质押/大额商誉）

### 2.5 会计质量红旗
（非经常性损益占比、折旧/研发资本化政策、商誉减值风险、关联交易、收入确认激进度）

### 2.6 营运资本与周转
（应收/存货/应付周转的**同比同期变化**——⚠️ 累计期口径不可跨季度横比；现金循环周期 CCC；应收或存货增速是否连续多季远超营收——压货/滞销信号）

### 2.7 经营指标诊断（解释 2.1~2.6 的"为什么"）

> **本节是全篇的因果链，须人工撰写，不得只贴表格。** 财务数字说"毛利率降了 2pct"，本节要回答"因为 ASP 降了 5% 而单位成本只降了 2%"。

**（1）量价拆分**：本期营收变化 = 量贡献 × 价贡献，二者各贡献多少 pct？
**（2）结构变化**：高端/新品/高毛利品类占比是升还是降？**结构升级是否伴随单位经济改善**（若高端占比↑但单位净利↓ → 升级是降价冲出来的，判「关注」）。
**（3）单位经济轨迹**：单位毛利、单位净利的**逐季序列**，规模效应（单位成本↓）与降价（ASP↓）谁跑得快？**剪刀差方向就是未来毛利率的方向**。
**（4）份额与竞争格局**：公司增速 − 行业增速 = 增速差；与主要对手的经营指标方向差。
**（5）背离检查**：逐条核对 SKILL.md 第四节第 3 点的七条背离形态，逐条给结论（命中 / 未命中）。
**（6）先行指标判断**：基于经营指标，判断下一季度财务指标大概率往哪走，并给出**验证口径**（如"若下季单车净利继续 <8000 元且销量增速 <5%，则确认以价换量失效"）。

## 三、读生意：生意质量与资本配置

### 3.1 回报率 ROE / ROIC（长期视角）
（连续 3~5 年水平与稳定性；拆解 ROE 来源：高净利率 / 高周转 / 高杠杆——判断是好生意还是杠杆堆出来的）

### 3.2 护城河与竞争地位
（壁垒类型：网络效应 / 转换成本 / 规模经济 / 品牌 / 牌照；市场份额与定价权；与同业的相对位置）

### 3.3 分部业务结构（增长引擎 / 利润池）
（各业务线营收、利润率、增速；谁是利润池、谁在减速、谁在接力；内部抵消是否掩盖问题。**每个分部都要做量价拆分**：量贡献多少、价贡献多少，避免只报分部营收）

### 3.4 资本配置与股东回报
（分红率/股息率；回购是否发生在低估时；并购记录与回报；Capex 用 ROI 视角——是否产生增量回报，而非只看投入额度。**用经营指标检验 Capex 效率**：单车 Capex / 单位产能投资 / 单店回收期）

### 3.5 同业对比（相对位置）
（与主要对手在增速、利润率、Capex、估值位置上的对照；相对位置比绝对值更能读出竞争态势。**优先比经营指标的方向差**——对手 ASP↑ 我↓ 说明定价权在流失；绝对值差受产品结构影响太大）

## 五、综合结论

- **财务健康度总评**：健康 / 关注 / 预警（一句话 + 主要依据）
- **经营指标（KPI）总评**：量 / 价 / 结构 / 份额 / 单位经济 各给方向，合成一句「**单位经济在改善还是在恶化**」——这是财务结论的先行判断。**KPI 与财务结论冲突时，以 KPI 为准并解释差异**（KPI 是先行变量）
- **趋势总判**：**在变好 / 走平 / 在变坏**（须点名哪几个指标、从哪一季开始转向；经营指标与财务指标各点名至少一个）
- **生意质量总评**：好生意？真钱？护城河？资本配置？一句话定性
- **业绩指引要点**：管理层下一步重心是什么，与当期财务、季度趋势**及经营指标轨迹**是否自洽（如喊高端化 → 高端占比有没有逐季提升）
- **主要风险与待跟踪项**：（列出 2~4 个最关键的风险点或需后续跟踪的变量，**每条必须落到下一季可观测的具体经营指标 + 观测口径 + 触发阈值**，禁止"关注行业需求变化"这类无法验证的表述。示例：
  - 「价格战侵蚀单车盈利」→ 跟踪**单车净利（元）= 扣非归母 ÷ 总销量**，下季 <8000 元且销量增速 <5% 则确认失血；
  - 「高端化不及预期」→ 跟踪**高端车销量占比（腾势+仰望+方程豹 ÷ 总销量，品牌口径）**，连续 2 季不升则判定战略未兑现；
  - 「渠道压库」→ 跟踪**批发销量 − 上险量缺口** 与 **渠道库存深度（月）**，>1.5 个月警戒。）

**一句话结论**：（用一句口语化、信息密度高的话概括公司当前状态、趋势方向、生意本质与管理层意图）
