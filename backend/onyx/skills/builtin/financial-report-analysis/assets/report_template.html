2.7 经营指标诊断（解释 2.1~2.6 的"为什么"）

本节是全篇的因果链，须人工撰写，不得只贴表格。财务数字说「毛利率降了 2pct」，本节要回答「因为 ASP 降了 5% 而单位成本只降了 2%」。

（1）量价拆分：{{本期营收变化 = 量贡献 × 价贡献，二者各贡献多少 pct}}

（2）结构变化：{{高端/新品/高毛利品类占比是升还是降；结构升级是否伴随单位经济改善——若高端占比↑但单位净利↓，判「关注」，升级是降价冲出来的}}

（3）单位经济轨迹：{{单位毛利、单位净利的逐季序列；规模效应（单位成本↓）与降价（ASP↓）谁跑得快——剪刀差方向就是未来毛利率的方向}}

（4）份额与竞争格局：{{公司增速 − 行业增速 = 增速差；与主要对手的经营指标方向差}}

（5）背离检查：{{逐条核对七条背离形态（量↑+单位净利↓ / 量↑+营收↓ / 量↑+存货↑ / 量↑+OCF↓ / 结构升级+毛利率↓ / 份额↑+单位净利↓ / 成本↓慢于单价↓），逐条给命中 or 未命中}}

（6）先行指标判断：{{基于经营指标判断下一季度财务指标大概率往哪走，并给出验证口径，如「若下季单车净利继续 <8000 元且销量增速 <5%，则确认以价换量失效」}}
