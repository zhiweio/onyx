# 税务内控测试

测试企业税务内控、评价控制缺陷或设计穿行测试时，读取本文件。

## 关键控制点图谱

税务内控的四个环节，每环节列出典型控制点：

| 环节 | 典型控制点 |
| --- | --- |
| 计税 | 税种税率维护与更新；收入确认时点与纳税义务时点对齐；进项发票查验与抵扣审批 |
| 申报 | 申报表编制与复核分离；申报前勾稽检查；数据从账簿到申报表的自动传递 |
| 缴纳 | 缴款审批与账户授权；缴款回单与申报表核对；税款计提与缴纳差异跟进 |
| 优惠备案 | 优惠适用条件年度复核；备查资料归档；资质到期预警 |

## 穿行测试

追踪一笔业务从发生到计税、申报、缴纳的全路径，验证控制真实生效：

1. 选样本：每类重大交易至少 1 笔（销售、采购、费用、资产、关联交易）。
2. 沿路径取证：合同 → 发票 → 入账 → 计税 → 申报表 → 缴款回单。
3. 记录每个控制点的执行人、方式与留痕。
4. 结论：控制是否在一笔完整业务上贯穿执行。

## 控制测试

验证控制在一贯运行，而非只在单笔业务上有效：

1. 定义控制目标与偏差标准（例如：申报复核 100% 执行，偏差=未留痕）。
2. 确定样本量：按控制频率与风险评级（高频控制样本更大）。
3. 抽样检查留痕：复核记录、审批流、系统日志。
4. 统计偏差率，评估是否可依赖；偏差超阈值时改为细节测试。

两者区别一句话：穿行测试证明"这条路通"，控制测试证明"每次都走"。

## 缺陷分类

| 等级 | 判定 | 示例 |
| --- | --- | --- |
| 重大缺陷 | 不能及时预防/发现重大错报 | 无申报复核，曾因此补税罚款 |
| 重要缺陷 | 严重削弱控制但未达重大 | 优惠备查资料缺失、依赖个别人经验维护税率 |
| 一般缺陷 | 影响效率或个别准确性 | 个别缴款回单未归档 |

每条缺陷写：环节 → 缺陷描述 → 证据 → 影响 → 整改建议（负责人/时限）。

## 与实质程序的联动

内控可依赖的环节减少实质性样本；重大缺陷环节扩大实质性程序，
并进入舞弊评估（fraud-red-flags.md）。
