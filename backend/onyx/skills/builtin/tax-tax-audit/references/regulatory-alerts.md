# 监管风险提示税务维度与合规自检

把会计监管风险提示纳入审计计划、或执行税务合规体检时，读取本文件。

## 使用方式

会计监管风险提示（财政部针对年报审计与会计监管发布的提示系列）中
涉及税务的维度，按"提示 → 常见问题 → 审计应对"三栏转成本项目的
程序清单。原文用网页检索获取（来源：财政部/证监局官网），引用带文号。

各号提示的覆盖面会更新；使用时检索最新目录确认适用版本，不要凭
记忆列举号对应的主题。

## 常见税务维度

历年提示中反复出现的税务相关问题域，审计计划至少各有一行应对：

| 问题域 | 常见表现 | 应对方向 |
| --- | --- | --- |
| 收入确认与纳税义务 | 收入确认时点操纵、跨期调节 | 申报比对 + 期后事项 |
| 政府补助与税前扣除 | 补助性质误判、不征税收入错配 | 补助文件 + 政策核验 |
| 重大非常规交易 | 关联重组、售后回租的税务处理 | 交易实质 + 专家利用 |
| 递延所得税 | 暂时性差异确认不完整 | 科目余额复核 |
| 研发费用加计 | 费用归集口径扩大、资料不实 | 立项资料 + 辅助账复核 |
| 公允价值计量 | 递延税与公允价值变动不联动 | 模型与假设复核 |

## 税务合规体检自检表

"做一下税务合规体检"时，按六步闭环压缩为五块自检，逐块给
"健康 / 关注 / 预警"评级与证据：

1. **申报一致性**：各税种申报数 vs 账面数 vs 发票台账，差异全解释。
2. **税负合理性**：税负率、毛利率与同业对比（同花顺 MCP 或行业数据），
   偏离要有结构性解释。
3. **内控有效性**：按 control-testing.md 图谱逐环节评估，列出缺陷等级。
4. **舞弊红旗扫描**：按 fraud-red-flags.md 清单逐项扫描，命中即列证据。
5. **优惠与备案**：适用优惠的条件复核与备查资料齐备性。

体检报告结构：范围 → 五块评级表 → 发现明细（证据+影响+建议）→
整改清单（负责人/时限）→ 附证据卡与来源清单。

## 评级口径

- 健康：无例外或例外已完全解释并有证据。
- 关注：存在例外，影响可控，需限期整改。
- 预警：存在重大缺陷、红旗未解释或可能导致补税罚款。

评级写依据，不凭感觉；证据不足的项标"待核验"并说明缺什么。
