# 涉税舞弊红旗清单

识别涉税舞弊风险、设计应对程序或评估异常信号时，读取本文件。
红旗是风险提示，不是舞弊结论；命中后扩大程序取证。

## 收入端

- 个人卡、股东卡、非公司账户收取经营款项；账外经营。
- 阴阳合同：备案合同与执行合同条款不一致，规避纳税义务。
- 收入确认时点与纳税义务时点长期错配；期末突击冲回收入。
- 平台流水（支付宝/微信）与申报销售额缺口大且无退货、手续费解释。
- 关联销售价格明显偏离市场，利润向低税负主体转移。

## 成本与发票端

- 虚开发票信号：进销倒挂、开票方经营能力与交易规模背离、
  无实物流转、资金回流（付款后部分回流至实控人或员工）。
- 大额"咨询费""推广费""服务费"无交付证据。
- 发票开具方集中在新设立、税收洼地或已走逃失联企业。
- 农产品收购发票、废旧物资发票自开自抵异常增长。

## 关联交易端

- 转移定价：关联采购价高售低、功能风险与利润不匹配。
- 同期资料缺失或利润水平偏离可比区间且无合理解释。
- 集团内无偿资金拆借、无偿许可知识产权未按独立交易原则计价。

## 综合指标

| 指标 | 异常方向 | 说明 |
| --- | --- | --- |
| 税负率 | 明显低于同业且无优惠解释 | 结合同花顺行业对标 |
| 进销项匹配 | 进项结构与销项业务不相关 | 例：卖服务进材料票 |
| 毛利率 | 波动与行业周期背离 | 配合存货盘点 |
| 现金流 | 净利润与经营现金流长期背离 | 追资金归集路径 |

## 应对程序

1. 命中红旗：记录红旗编号、证据与初步解释。
2. 扩大样本或覆盖期间；追资金流（银行流水勾稽）与货物流（物流单据）。
3. 管理层访谈要求解释并留书面答复；解释不成立的进入缺陷/发现清单。
4. 涉嫌重大违法的，提示管理层咨询专业人士并评估对报告的影响。
