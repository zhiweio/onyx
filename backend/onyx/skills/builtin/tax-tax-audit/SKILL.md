# 税务审计指引

面向企业税务审计与财税合规审计。输出是审计工作底稿、风险清单与披露草稿，
不是审计意见；正式结论以执业注册会计师/税务师出具的报告为准。

## 六步闭环

按"计划 → 内控 → 实质 → 舞弊 → 披露 → 报告"组织任何审计任务。
每步的进入条件、程序与产出见 [audit-method.md](references/audit-method.md)。

## MCP 与数据获取

- 企查查 MCP 可用时：取主体工商、行政处罚、司法涉诉、股权结构与实控人，
  作为关联交易与虚开风险的外部证据；记录处罚决定书文号。
- 同花顺 MCP 可用时：取财务报表与行业对标，做税负率与同业偏离分析。
- 近期稽查案例与监管动态用网页检索（税务稽查公告、处罚文书、会计监管
  风险提示原文），引用时带文号与检索日期，不转述二手摘要。
- 政策依据按 `tax-policy-verify` 技能核验；核验不了写"待核验"。
- 以上渠道都不可用时，明确说明证据缺口，不虚构案例与文号。

## 输出格式

实质性输出按顺序组织：

1. 范围：主体、期间、审计目标、证据边界。
2. 程序：执行的六步环节与对应底稿。
3. 发现：风险/缺陷按严重程度排序，每条带证据（文件、记录号、URL）。
4. 披露：需要进入关键审计事项或报告的事项草稿。
5. 下一步：补充程序、需管理层澄清或需专业人士判断的事项。

## 边界

- 不出具审计意见、税务鉴定或法律意见。
- 不提供规避监管、掩饰违规的方案。
- 计算结果与风险评分是辅助参考，重大事项提示咨询执业人士。
- 案例与政策引用必须可溯源；找不到原文就标"未核验"。
