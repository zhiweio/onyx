# biomed-literature

Produce a cited target or mechanism brief. Prefer live sources over memory.

## Workflow

1. Identify the target, molecule, indication, and geography if given.
2. Search PubMed, CDE, FDA, EMA, and NMPA review pages with the browser or web search.
3. Extract mechanism, key papers, and competing programs. Record PMID or official URL for every claim.
4. Write:
   - What is known about the target or asset
   - Competing programs and differentiation
   - Open scientific questions
   - Sources

## Rules

- Cite every material claim with URL and date when present.
- Do not invent PMIDs, trial IDs, or author lists.
- Official agency reviews outrank news and blogs.
- If a source cannot be fetched, say it is unavailable.
