# listed-co-red-blue-review

No MCP. Read the existing extracts, ratios, credit notes, and IP store.

1. **Red** — List the claims that the evidence does not support. Write
   `outputs/review/red.md`.
2. **Blue** — Answer each challenge with a file path or mark it open. Write
   `outputs/review/blue.md`.

A claim without a file path is an open issue, not a finding.
