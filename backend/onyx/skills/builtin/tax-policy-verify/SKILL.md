# 政策核验

任何涉及中国大陆税费政策的结论，先核验、后回答。本技能只做核验与证据组织，
不覆盖申报流程与报表编制（那两个任务用 `caishui-skill`）。

## 反幻觉红线

不编造、不猜测：

- 政策名称、文号、条款、发布与施行日期、截止日期。
- 税率、征收率、预征率、优惠条件、免税额度、申报期限。
- 地方执行口径、电子税务局菜单路径、导入模板版本。
- 税务机关答复、12366 口径、平台提示语。
- 未核验的"行业惯例"或"通常做法"。

无法联网、官方页面打不开、只有第三方文章、地区信息缺失、所属期不明、
文件有效性不确定时，结论标为 `无法核验` 或 `待核验`。可以给核验路径，
不把推测写成事实。

## 官方来源阶梯

按顺序取证，高位阶优先：

1. 法律、行政法规、国务院文件。
2. 财政部、国家税务总局公告与规范性文件。
3. 国家税务总局政策法规库与政策解读。
4. 省、市、区县税务局公告、通知、办税指南。
5. 电子税务局办税指南、平台公告、用户提供的当前页面截图。
6. 12366 问答与官方新媒体只能作辅助，不能替代公告原文。

非官方文章只用来找线索，最终依据必须回到官方来源。

## 核验步骤

每个政策敏感结论都执行 [policy-freshness.md](references/policy-freshness.md)
的完整流程，要点：

1. 先固定问题框架：税种、纳税人身份、主体类型、行业、所属期、地区。
2. 检索官方来源（见下节），优先取所属期内有效的文件，而不是最新但不适用的。
3. 检查时效关键词：`自...起施行`、`执行至`、`废止`、`失效`、
   `部分条款废止`、`另有规定`、`由省级税务机关确定`。
4. 输出证据卡：标题、发布机关、文号、发布/施行/截止日期、适用地区、
   核验日期、链接、相关性、状态（现行 / 已过期 / 已废止 / 地方待核验 / 不确定）。
5. 地方适用性未确认时直接说明；影响正式申报的，不给"可直接申报"的结论。

## 地区口径

涉及省市区县、主管税务机关、地方费种、核定征收、数电票额度、平台路径时，
按 [regional-source-strategy.md](references/regional-source-strategy.md) 执行：
先全国口径，再地方执行；注册地与经营地不一致时分别记录；来源冲突时实体规则
看高位阶法规、流程口径看主管税务机关，并标注冲突。

## 检索工具

优先用官方站内检索脚本（中国政府网 + 国家税务总局，纯标准库）：

```
python .opencode/skills/tax-policy-verify/scripts/search_official_policy.py \
  "增值税 小规模纳税人 减免" --json
```

- 结果只是证据候选，用于答复或申报前要打开页面核对正文与时效状态。
- 脚本不可用或结果不足时，用宿主的网页搜索补充；检索词带上所属期与地区。
- 工作区配置了同花顺 / 企查查 MCP 时，主体工商与处罚信息用 MCP 取，
  政策原文仍以官方来源为准。

## 回答分层

- **官方依据**：只写官方文件能直接支持的内容。
- **适用判断**：结合纳税人事实、地区、所属期作出的判断，标注假设。
- **待核验事项**：缺地区、所属期、地方来源、纳税人类型、账簿事实时列出。

不用"保证享受""一定可以""直接这样报"这类表述，除非事实、政策、
地方口径三者都已核验。
